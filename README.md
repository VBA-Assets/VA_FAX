# VA FAX — インターネットFAX送信用PDF変換ツール

VA FAXは、お手元のPDFファイルを、インターネットFAXサービスで送信できる形式
（例：MOT/FAXでは A4・モノクロ・3MB以内の画像PDF）へワンクリックで変換する、
Windows用の無料ツールです。法律事務所をはじめ、FAXでの書類送付が多い事業所での
利用を想定しています。

## こんな作業を自動化します

インターネットFAXサービスには、送信ファイルに厳しい制約があります
（対応用紙サイズ・カラー不可・ファイル容量の上限など）。
Wordから出力したPDFやスキャンした資料をそのまま送ろうとすると、
「容量オーバーで送れない」「B4の資料が混ざっていて弾かれる」といった
手戻りが起こりがちです。VA FAXは次の処理をまとめて自動で行います。

- **送信票と本文の結合**：FAXに添える送信票（送付状）のPDFと送りたい文書のPDFを、
  PDF編集アプリを使わずに、追加した順のまま1つのPDFに結合して変換します
- **全ページの画像化**：テキストデータ付きPDFで起こりうるフォントの置き換わり・
  送信失敗を、全ページを画像に変換することで回避します
- **用紙の正規化**：対応外サイズ（B4・A3等）のページをA4に収めます（縦横比は維持）
- **モノクロ化と圧縮**：FAXで最も一般的な白黒2値（G4圧縮）へ変換します。
  写真の多い資料向けにグレースケール（JPEG圧縮）も選べます
- **容量上限への自動対処**：上限を超える場合、「解像度・品質を下げて再実行」
  （送信回数を増やさない）または「分割して再実行」（画質を下げない。
  `文書名_1of3.pdf` のような連番ファイルに分割）のどちらかで自動調整します
- **変換前後のプレビュー**：変換前に仕上がりのイメージを、変換後に実際の出力
  そのものを画面で確認できます

対応FAXサービスのプロファイルを同梱しています：
**MOT/FAX**（標準）・**MOVFAX**・**メッセージプラス**・**秒速FAX送信**・
**eFax**（参考値）・**jFax**（参考値）。このほか、お使いのサービスの公表仕様を
入力して使う「カスタム」も選べます。

> **ご注意**：各プロファイルの制約値は、いずれもサービス各社が公表している
> 仕様に基づくものです（実際のFAX送信による動作検証は行っていません）。
> eFax・jFaxプロファイルの容量上限（合計1MB）は、公式文書で未確認の
> 参考値です。どのサービスをお使いの場合も、初回はご自身のFAX番号宛の
> テスト送信で仕上がりをご確認ください。

## 動作環境

- Windows 10 / 11（64bit）
- インストール不要。`VA_FAX.exe` をダブルクリックするだけで起動します
- インターネット接続不要（完全ローカル動作。FAXの送信操作自体は、
  各インターネットFAXサービスの画面で別途行ってください）
- Macでは、ソースから動かす場合に限り使えます（動作は保証しません。下記）

### Macで動かす（動作は保証しません）

Mac用の実行ファイルは配っていません。配布物の `source` フォルダ（GitHubの
VBA-Assets/VA_FAX と同じもの）を、Python 3（Tkの入ったもの。python.orgの
macOS用インストーラーのPythonには入っています）で動かしてください。

```
cd source
python3 -m pip install -r requirements.txt
python3 src/main.py
```

- **標準のMOT/FAXはMacから使えません**：MOT/FAXの公表仕様では、利用できる機器が
  Windows PC・Android・iPhoneで、Macは含まれていません。Macでは、お使いのサービス
  （MOVFAX・メッセージプラス・秒速FAX送信など）のプロファイルを選んでください。
  そのサービスをMacから使えるかは、各サービスの案内でご確認ください
- 設定・追加プロファイル・ログは、`%APPDATA%\VA_FAX` ではなく、ホームの
  `.va_fax` フォルダに置かれます
- Ctrlのキー（Ctrl+Z・Ctrl+A など）は、⌘でも効きます
- Macの実機では動作を確かめていません

## 使い方

1. `VA_FAX.exe` を起動します（初回はお使いのFAXサービスを選択します）
2. 変換したいPDFを画面にドラッグ＆ドロップ（または「入力元...」で選択）します。
   複数のPDFを入力すると、上から順に1つのPDFへ結合して変換されます
   （例：送信票→本文の順に追加）。あとから追加・削除・並べ替えができます
   （行をクリックして選んでから Delete キー、または行をマウスでドラッグ。
   欄の外へドラッグすると一覧から取り除かれます）。Ctrl+Z で元に戻せます
3. 事前診断の結果（ページ数・用紙サイズ・カラーの有無など）と、
   左側のプレビューで仕上がりイメージを確認します
4. 必要に応じて処理内容（圧縮方式・容量超過時の処理方式など）を変更します
5. 「変換して出力」を押します。完了後、プレビューが実際の出力の表示に
   切り替わり、「出力フォルダを開く」からすぐにファイルを確認できます

あとは出力されたPDFを、お使いのインターネットFAXサービスの送信画面で
アップロードするだけです。

## はじめて起動するときの注意

- **起動に数秒〜十数秒かかることがあります**：VA_FAX.exeは必要なファイルを
  1つにまとめた形式（onefile）のため、起動のたびに内部で展開処理を行います。
  ダブルクリック後、画面が出るまでしばらくお待ちください
- **「WindowsによってPCが保護されました」（SmartScreen）が表示された場合**：
  署名のない新しいアプリのため、初回は警告が出ることがあります。
  「詳細情報」をクリック →「実行」を選択してください
- **初回はテスト送信を**：はじめてお使いになる際は、変換したPDFをご自身の
  FAX番号宛に一度送信し、受信側での仕上がりをご確認いただくことをおすすめします。
  特にグレースケールを選んだ場合、サービス側の処理で黒つぶれ・白飛びが
  起こる場合があります

## 守秘設計（大切な書類を扱う方へ）

法律事務所等での利用を想定し、文書の秘密が外部に出ない設計としています。

- **完全ローカル動作**：ネットワーク通信を行うコードを一切含みません。
  文書がPCの外に送られることはありません
- **文書情報を保存しません**：変換中のデータはすべてメモリ内で処理し、
  一時ファイルを作りません。ツールが設定として保存するのはフォルダパス等の
  画面状態のみで、文書のファイル名・内容は保存しません
- **ログにもファイル名を残しません**：不具合調査用のログには技術情報
  （ページ番号・解像度など）のみを記録し、ファイル名・パスは記録しません
- **変換レポートは初期設定では保存しません**：処理内容の記録（変換レポート）が
  必要な場合のみ有効にでき、その場合も出力PDFと同じフォルダにのみ保存されます
- **文書のプロパティ情報も引き継ぎません**：入力PDFに埋め込まれた作成者名・
  タイトル・作成アプリ等のメタデータは、出力PDFには一切含まれません
  （出力はページ画像から新しく組み立てるため、引き継がれる経路がありません）
- **入力ファイルは変更しません**：元のPDFはそのまま残ります

## 複数PCでの利用（事務所内での設定配布）

設定ファイル（`%APPDATA%\VA_FAX\settings.json`）を他のPCの同じ場所へ
コピーすると、FAXサービスの選択と変換の既定設定を一括で揃えられます。
