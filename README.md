# VA FAX — インターネット FAX 送信用 PDF 変換ツール

VA FAX は、インターネット FAX サービスで送る PDF の準備を、このツールだけで済ませる
Windows 用の無料ツールです。ふつうの PDF 編集アプリと同じようにファイルを開いて
ページを整えて保存すると、お使いのサービスの送信条件
（例：MOT/FAX では A4・モノクロ・3MB 以内）に合う画像 PDF にして保存します。
法律事務所をはじめ、FAX での書類送付が多い事業所での利用を想定しています。

## こんな作業を、このツールだけで行えます

インターネット FAX サービスには、送信ファイルに厳しい制約があります
（対応用紙サイズ・カラー不可・ファイル容量の上限など）。
Word から出力した PDF やスキャンした資料をそのまま送ろうとすると、
「容量オーバーで送れない」「B4の資料が混ざっていて弾かれる」といった
手戻りが起こりがちです。VA FAX は次の作業をまとめて行います。

- **ページの編集**：送信票（送付状）と本文を1つにまとめる、要らないページを
  削除する、順番を入れ替える、向きの違うページを回す、といった作業を、
  サムネイルの上で行えます（元に戻す・やり直す、右クリックメニューにも対応）
- **送付書（兼受領書）の作成**：訴訟で相手方に書面を FAX で直送するときの送付書を作って、
  先頭に入れられます。書類の一覧は、入れたファイルの名前から自動で作ります
  （VA mints の「甲001 売買契約書」の形の名前は「甲第1号証」と書きます）
- **ページ番号**：保存する各ページの上端に「1/12」の形で通し番号を入れ、
  受け手が全ページ届いたかを確かめられるようにします
- **画像の取り込み**：スマートフォンで撮った写真やスキャンした画像
  （JPEG・PNG）を、ページとして入れられます
- **全ページの画像化**：テキストデータ付き PDF で起こりうるフォントの置き換わり・
  送信失敗を、全ページを画像に変換することで回避します
- **用紙の正規化**：対応外サイズ（B4・A3等）のページを A4 に収めます（縦横比は維持）
- **モノクロ化と圧縮**：FAX で最も一般的な白黒2値（G4 圧縮）へ変換します。
  写真の多い資料向けにグレースケール（JPEG 圧縮）も選べます。
  画像にせずそのまま保存する「何もしない」も選べます
- **容量上限への自動対処**：上限を超える場合、「解像度・品質を下げて再実行」
  （送信回数を増やさない）または「分割して再実行」（画質を下げない。
  `文書名_1of3.pdf` のような連番ファイルに分割）のどちらかで自動調整します
- **保存の前後のプレビュー**：保存の前に仕上がりのイメージを、保存の後に実際に
  保存した内容そのものを画面で確かめられます

対応 FAX サービスのプロファイルを同梱しています：
**MOT/FAX**（標準）・**MOVFAX**・**メッセージプラス**・**秒速FAX送信**・
**eFax**（参考値）・**jFax**（参考値）。このほか、お使いのサービスの公表仕様を
入力して使う「カスタム」も選べます。

> **ご注意**：各プロファイルの制約値は、いずれもサービス各社が公表している
> 仕様に基づくものです（実際の FAX 送信による動作検証は行っていません）。
> eFax・jFax プロファイルの容量上限（合計1MB）は、公式文書で未確認の
> 参考値です。どのサービスをお使いの場合も、初回はご自身の FAX 番号宛の
> テスト送信で仕上がりを確かめてください。

## 動作環境

- Windows 10 / 11（64bit）
- インストール不要。`VA_FAX.exe` をダブルクリックするだけで起動します
- インターネット接続不要（完全ローカル動作。FAX の送信操作自体は、
  各インターネット FAX サービスの画面で別途行ってください）
- Mac では、ソースから動かす場合に限り使えます（動作は保証しません。下記）

### Mac で動かす（動作は保証しません）

Mac 用の実行ファイルは配っていません。配布物の `source` フォルダ（GitHub の
VBA-Assets/VA_FAX と同じもの）を、Python 3（Tk の入ったもの。python.org の
macOS 用インストーラーの Python には入っています）で動かしてください。

```
cd source
python3 -m pip install -r requirements.txt
python3 src/main.py
```

- **標準の MOT/FAX は Mac から使えません**：MOT/FAX の公表仕様では、利用できる機器が
  Windows PC・Android・iPhone で、Mac は含まれていません。Mac では、お使いのサービス
  （MOVFAX・メッセージプラス・秒速FAX送信など）のプロファイルを選んでください。
  そのサービスを Mac から使えるかは、各サービスの案内で確かめてください
- 設定・追加プロファイル・ログは、`%APPDATA%\VA_FAX` ではなく、ホームの
  `.va_fax` フォルダに置かれます
- Ctrl のキー（Ctrl+O・Ctrl+S・Ctrl+Z など）は、⌘でも効きます
- Mac の実機では動作を確かめていません

## 使い方

1. `VA_FAX.exe` を起動します（初回はお使いの FAX サービスを選択します）
2. 画面上部のリボンの［開く］で、送りたい PDF を開きます（ウィンドウへの
   ドラッグ＆ドロップでも開けます。起動したときのページのない文書に、［追加］で書面を
   入れることもできます。1回の送信の分を保存し終えたら、［閉じる］〔Ctrl+W〕で閉じます）
3. 送信票などのページを足すときは［追加］（サムネイルの間へのドラッグ＆ドロップでも可）、
   要らないページは［削除］、向きの違うページは［回転］で整えます。
   サムネイルをつかんで動かすと、順番を入れ替えられます。Ctrl+Z で元に戻せます。
   送付書をこのツールで作るときは、送るページをすべて入れてから「送付書」の［作成］を押します
   （事務所名などは、初めに［ファイル］→［オプション］の「送付書」で入力します）
4. 診断の結果（ページ数・用紙サイズ・カラーの有無など）と、
   左側のプレビューで仕上がりイメージを確かめます
5. 必要に応じて処理内容（圧縮方式・容量超過時の処理方式など）を変更します
6. ［保存］を押し、保存する場所と名前を指定します（名前の初めの値は「元の名前_fax.pdf」で、
   元のファイルは残ります）。開いたファイルに上書きするときは、同じ名前を選びます（置き換えてよいかの確認が出ます）

あとは保存した PDF を、お使いのインターネット FAX サービスの送信画面で
アップロードするだけです。

## はじめて起動するときの注意

- **起動に数秒〜十数秒かかることがあります**：VA_FAX.exe は必要なファイルを
  1つにまとめた形式（onefile）のため、起動のたびに内部で展開処理を行います。
  ダブルクリック後、画面が出るまでしばらくお待ちください
- **「Windows によって PC が保護されました」（SmartScreen）が表示された場合**：
  署名のない新しいアプリのため、初回は警告が出ることがあります。
  「詳細情報」をクリック →「実行」を選択してください
- **初回はテスト送信を**：はじめてお使いになる際は、保存した PDF をご自身の
  FAX 番号宛に一度送信し、受信側での仕上がりを確かめることをおすすめします。
  特にグレースケールを選んだ場合、サービス側の処理で黒つぶれ・白飛びが
  起こる場合があります

## 守秘設計（大切な書類を扱う方へ）

法律事務所等での利用を想定し、文書の秘密が外部に出ない設計としています。

- **完全ローカル動作**：ネットワーク通信を行うコードを一切含みません。
  文書が PC の外に送られることはありません
- **文書情報を保存しません**：ページの編集や変換の途中のデータはすべて
  メモリ内で処理し、一時ファイルを作りません。ツールが設定として保存するのは
  最後にファイルを開いたフォルダの場所・ウィンドウの大きさ等の画面状態と、送付書の
  送信者（事務所名・住所・電話・FAX・弁護士名）のみで、文書のファイル名・内容は
  保存しません（「最近使ったファイル」の一覧もありません）。送付書を入れた文書を
  保存したときだけ、その送付書の入力（宛先・事件・書類の一覧など）を、保存した
  PDF と同じフォルダの「FAX送付書データ」フォルダに保存します
- **ログにもファイル名を残しません**：不具合調査用のログには技術情報
  （ページ番号・解像度など）のみを記録し、ファイル名・パスは記録しません
- **文書のプロパティ情報も引き継ぎません**：二値化・グレースケールで保存した
  PDF には、元の PDF に埋め込まれた作成者名・タイトル・作成アプリ等の
  メタデータは含まれません（ページ画像から新しく組み立てるため）。
  画像の位置情報等も含まれません
- **保存するまでファイルを書き換えません**：ページの編集は保存するまで
  画面の上だけで行われます。開いたファイルと同じ名前で保存するときは、置き換えてよいかの確認が出ます。
  保存は一時的な名前で書き終えてから置き換えるので、途中で失敗しても
  元のファイルは壊れません。ページの材料として追加したファイルは変更しません
- **相談用の診断情報にも中身は入りません**：［ヘルプ］→［診断情報をコピー］で
  コピーされるのは、版・OS・設定の数値・件数・エラーの型と起きた場所だけで、
  開いた・保存したファイルの名前、ファイルやフォルダの場所は含まれません

## 複数 PC での利用（事務所内での設定配布）

設定ファイル（`%APPDATA%\VA_FAX\settings.json`）を他の PC の同じ場所へ
コピーすると、［ファイル］→［オプション］の内容（FAX サービスの選択・処理内容の
既定値・保存の設定・送付書の送信者）を一括で揃えられます。
