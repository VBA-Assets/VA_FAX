# 第1章 ツールの概要

## 1.1 これは何をするツールか

**VA FAX**は、お手元のPDFファイルを、インターネットFAXサービスで送信できる形式へ自動変換するためのツールです。標準対応のMOT/FAXでは「A4・モノクロ・3MB以内の画像PDF」という送信条件がありますが、Wordから出力したPDFやスキャンした資料をそのまま送ろうとすると、「容量オーバーで送れない」「B4の資料が混ざっていて弾かれる」といった手戻りが起こりがちです。VA FAXは、この条件への適合作業をまとめて自動で行います。

- **送信票と本文の結合**：FAXに添える送信票（送付状）のPDFと送りたい文書のPDFを、PDF編集アプリを使わずに、追加した順のまま1つのPDFに結合して変換します（第3章3.3参照）
- **全ページの画像化**：テキストデータ付きPDFで起こりうるフォントの置き換わり・送信失敗を、全ページを画像に変換することで構造的に回避します
- **用紙の正規化**：対応外サイズ（B4・A3等）のページをA4に収めます（縦横比は維持）
- **モノクロ化と圧縮**：FAXで最も一般的な白黒2値（G4圧縮）へ変換します。写真の多い資料向けにグレースケール（JPEG圧縮）も選べます
- **容量上限への自動対処**：上限を超える場合、「解像度・品質を下げて再実行」（送信回数を増やさない）または「分割して再実行」（画質を下げない）のどちらかで自動調整します

**VA FAXが行うのはPDFの変換までです。** FAXの送信操作は、変換後のPDFをお使いのインターネットFAXサービスの画面でアップロードして行ってください。

## 1.2 対応FAXサービス

送信条件（容量上限・対応用紙等）はサービスごとに異なるため、VA FAXは「サービスプロファイル」として切り替えられる仕組みになっています。次のプロファイルを同梱しています。

| サービス | 備考 |
|---|---|
| MOT/FAX（標準） | 公式仕様に基づく |
| MOVFAX | 公式仕様に基づく |
| メッセージプラス | 公式仕様に基づく |
| 秒速FAX送信 | 公式仕様に基づく |
| eFax | 容量上限（合計1MB）は参考値（公式未確認） |
| jFax | 容量上限（合計1MB）は参考値（公式未確認） |
| カスタム | お使いのサービスの公表仕様を入力して利用 |

各プロファイルの制約値は、いずれもサービス各社が公表している仕様に基づくものです（実際のFAX送信による動作検証は行っていません）。**どのサービスをお使いの場合も、初回はご自身のFAX番号宛にテスト送信して仕上がりをご確認ください。** 特にeFax・jFaxは容量上限が公式未確認の参考値のため、画面上にも同じ注意が表示されます。

## 1.3 安全性に関する設計方針

法律事務所等での利用を想定し、文書の秘密が外部に出ない設計としています。

- **完全ローカル動作**：いかなる処理段階でも外部ネットワーク通信を行いません。クラウドAPI・外部変換サービス・利用状況の送信・自動アップデート確認、いずれも実装していません。文書の内容がお使いのパソコンの外部に送信されることはありません。
- **文書情報を保存しない**：変換中のデータはすべてメモリ内で処理し、一時ファイルを作りません。ツールが設定として保存するのはフォルダパス等の画面状態のみで、変換したファイルの名前・内容・履歴は保存しません。
- **文書のプロパティ情報も引き継がない**：入力PDFに埋め込まれた作成者名・タイトル・作成アプリ等のメタデータは、出力PDFには一切含まれません（出力はページ画像から新しく組み立てるため、引き継がれる経路がありません）。
- **ログにもファイル名を残さない**：不具合調査用のログには技術情報（ページ番号・解像度・エラー種別等）のみを記録し、ファイル名・パスは記録しません。
- **原本を書き換えない**：入力PDFを変更・移動・削除することはなく、指定した出力先への書き出しのみを行います（出力先が入力ファイルと同一になる指定はエラーとして拒否されます）。

# 第2章 導入方法

## 2.1 配布物の構成

本ツールは、次のファイル一式で構成されています。

| ファイル | 内容 |
|---|---|
| `VA_FAX.exe` | 実行ファイル本体（Python環境不要。これだけで動作します） |
| `README.md` | 利用者向け説明（VBAアセット掲載文と同一） |
| `VA_FAX_操作マニュアル_Ver112.pdf` | 本マニュアル |
| `LICENSE.txt` | ライセンス条文（MIT License） |
| `source/` | ソースコード一式（Python。改変・再配布はライセンス条件の範囲内で自由） |

## 2.2 起動方法

1. `VA_FAX.exe` を任意のフォルダ（デスクトップ等）に置き、ダブルクリックして起動します。インストール・Python環境は不要です。
2. **起動に数秒〜十数秒かかることがあります。** 必要なファイルを1つにまとめた形式（onefile）のため、起動のたびに内部で展開処理を行います。画面が出るまでお待ちください。
3. Windows Defender SmartScreen等により「WindowsによってPCが保護されました」と警告が表示される場合がありますが、これは未署名の実行ファイルに一般的に表示されるものです。「詳細情報」をクリックし、「実行」を選択してください。内容にご不安がある場合は、`source/` フォルダ内のソースコードをご確認いただくか、ご自身の環境でビルドし直してご利用ください。

## 2.3 動作環境

Windows 10 / 11（64bit）を想定しています（法律事務所の一般的なPC環境に合わせています）。

Macでは、同梱のソースコード（`source/` フォルダ。GitHubの VBA-Assets/VA_FAX と同じもの）から動かせます（動作は保証しません。Macの実機では動作を確かめていません）。Mac用の実行ファイルは配っていません。Python 3（Tkの入ったもの。python.orgのmacOS用インストーラーのPythonには入っています）を入れ、ターミナルで `source` フォルダに移って、`python3 -m pip install -r requirements.txt` で必要な部品を入れてから、`python3 src/main.py` で起動します。

- **標準のMOT/FAXはMacから使えません。** MOT/FAXの公表仕様では、利用できる機器がWindows PC・Android・iPhoneで、Macは含まれていません。Macでは、お使いのサービス（MOVFAX・メッセージプラス・秒速FAX送信など）を選んでください。そのサービスをMacから使えるかは、各サービスの案内でご確認ください。
- 設定・追加プロファイル・ログは、`%APPDATA%\VA_FAX` ではなく、ホームの `.va_fax` フォルダに置かれます。
- Ctrlのキー（Ctrl+Z・Ctrl+A など）は、⌘でも効きます。

## 2.4 初回起動：FAXサービスの選択

はじめての起動時に「お使いのFAXサービスを選んでください」という画面が表示されます。契約中のサービスを選んで「決定」を押してください。ここで選んだサービスの制約（容量上限・対応用紙）に合わせて変換が行われます。あとから変更する場合は、メニューの「設定」→「FAXサービスを変更...」です。

「カスタム」を選ぶと、サービス名・最大ファイルサイズ・ページ数上限・対応用紙サイズ等を自分で入力できます（一覧にないサービスをお使いの場合）。

# 第3章 基本的な使い方

## 3.1 画面の見かた

メイン画面は左右2つの領域に分かれています（境界はドラッグで動かせます）。

**左側：プレビュー欄** — ページのサムネイル一覧と、選択中ページの拡大表示です。下部に「変換イメージ：1 / 3 ページ目」のような表示状態が出ます（3.5参照）。

**右側：操作欄（上から順に）**

| 項目 | 説明 |
|---|---|
| 対象サービス | 選択中のFAXサービスと制約値（例「MOT/FAX（上限3MB・A4）」） |
| 入力ファイル | 変換するPDF（複数可・1行1ファイル）。ドラッグ＆ドロップまたは「入力元...」で追加（3.3参照） |
| 事前診断結果 | ページ数・用紙サイズ・カラーの有無・テキストの有無など |
| 処理内容の選択 | 圧縮方式などの変換設定（3.4参照） |
| 出力ファイル | 出力先のパス。「出力先...」で変更可能 |
| 変換して出力 | 変換を実行し、出力ファイルに保存します |
| 処理ログ | ページごとの処理内容・自動調整の記録 |
| 出力フォルダを開く | 変換完了後、出力先フォルダをエクスプローラーで開きます |

## 3.2 変換の手順

1. 変換したいPDFを画面へ**ドラッグ＆ドロップ**します（「入力元...」ボタンでも可）
2. **事前診断結果**と左側の**プレビュー**（変換後の見込み）を確認します
3. 必要なら**処理内容**を変更します（通常は初期設定のままで問題ありません）
4. **「変換して出力」**を押します

完了すると通知が表示され、プレビューが「変換結果」（実際に出力された内容）に切り替わります。「出力フォルダを開く」でファイルの場所をすぐに開けます。あとは出力されたPDFをFAXサービスの画面でアップロードするだけです。

複数のPDF（送信票＋本文など）を1件のFAXとしてまとめて送りたい場合は、続けてファイルを追加します（3.3参照）。

## 3.3 複数のPDFをまとめて送る（送信票の添付）

FAXでは、送信票（送付状）を1枚目に付けて送るのが一般的です。VA FAXでは、送信票のPDFと送りたい文書のPDFを入力欄に順に追加するだけで、**上から順に結合した1つのPDF**として変換できます。事前にPDF編集アプリで結合しておく必要はありません。

**追加** — ファイルが入力済みの状態で、さらにファイルをドラッグ＆ドロップするか「入力元...」（複数選択できます）で選ぶと、一覧の末尾に追加されます。追加のたびに事前診断とプレビューが結合後の内容に更新され、診断結果に「入力ファイル数：2件（上から順に結合して変換します）」のように表示されます。

**選択** — 削除・並べ替えなどの操作は、いずれも**先に対象の行を選んでから**行います。行をクリックすると、その行全体が反転表示になり、これが操作の対象です。複数のファイルをまとめて選ぶときは、先頭の行をクリックしたあと最後の行を**Shift**キーを押しながらクリックします（**Shift**キーを押しながらのドラッグでも選べます）。すべて選ぶには**Ctrl+A**を押します。**↑↓**キー、**PageUp／PageDown**、**Home／End**でも選択行が移動します（**Shift**キーを併用すると範囲が広がります）。選択を解除するには**Esc**キーを押すか、一覧の下の余白をクリックします。何も選択していないときは、削除・切り取り・コピーは動作しません。

**削除** — 削除したいファイルの行を選んで、**Delete**キーまたは**BackSpace**キーを押します。行を**入力欄の外へドラッグして放す**方法でも削除できます（マウスカーソルがゴミ箱の絵に変わったところで放してください）。いずれの場合も、一覧から取り除かれるだけで、パソコン上のファイルは削除されません。誤って消してしまったときは**Ctrl+Z**で戻せます。

**並べ替え（ドラッグ）** — 移動したいファイルの行をマウスでつかんで、入れたい位置まで動かして離します（つかんだ時点でその行が選択されるので、あらかじめクリックしておく必要はありません）。動かしている間、挿入される位置が青い線で表示されます。複数行を選択してからその中をドラッグすると、選んだ範囲がまとめて移動します。一覧が3行に収まらない場合は、ポインタを欄の上端・下端に近づけると自動でスクロールします。途中でやめたいときは、マウスのボタンを離す前に**Esc**キーを押します。

**並べ替え（キーボード）** — 移動したい行を選んで**Ctrl+X**（切り取り）を押し、入れたい位置の行を選んで**Ctrl+V**（貼り付け）を押す方法もあります。貼り付けは**選んだ行の前**に入ります（何も選んでいないときは末尾に追加されます）。**Ctrl+C**（コピー）も使えます。

**元に戻す** — 追加・削除・切り取り・貼り付け・ドラッグによる並べ替えの操作は、**Ctrl+Z**で直前の状態に戻せます（繰り返し押すとさらに前まで戻れます）。

入力欄のファイル名を文字単位で書き換えることはできません（表示と実際の変換対象がずれることを防ぐため、操作は上記の行単位のものに限定しています）。件数の上限はありませんが、一度に10件を超えて追加しようとした場合は確認画面が表示されます。ページ数・容量の上限は、結合後のPDF全体に対して通常どおり適用されます。出力ファイル名は、1件目（一番上）の入力ファイル名をもとに決まります（3.6参照）。

## 3.4 処理内容の選択

各処理は、実行前に必ず画面上のチェックボックス・ラジオボタンで内容を確認・選択してから実行される仕組みになっています。選択肢の副作用（「カラー・階調情報が失われます」等）は画面上にも表示されます。

**圧縮方式**

| 選択肢 | 説明 |
|---|---|
| **二値化（白黒・G4圧縮）**（初期値） | 白黒2値に変換します。カラー・階調情報は失われますが、FAXで最も一般的な原稿形式で、ファイルも小さくなります |
| **グレースケール（JPEG圧縮）** | 濃淡を残します。写真・図版中心の資料向け。ただしサービス側で黒つぶれ・白飛びが起こる場合があるため、実際に送信して仕上がりをご確認ください |

二値化の**ディザ方式**は「自動」（初期値）のままにしておくと、ページ内容から最適な方式を1ページずつ自動選択します（文字・線画のページには単純閾値、写真・グラデーションのページには誤差拡散）。手動で「単純閾値」「誤差拡散」に固定することもできます。グレースケールの**JPEG品質**は高・中（初期値）・低から選択します。

**容量超過時の処理方式** — 変換結果がサービスの容量上限を超えた場合の対処方法です（常に自動で対処します）。

| 選択肢 | 説明 |
|---|---|
| **解像度・品質を下げて再実行**（初期値） | 画質を段階的に下げて1ファイルに収めます。送信回数を増やさずに済みます |
| **分割して再実行** | 画質を下げずに、複数のPDFに分割します。ファイル名は `文書名_1of3.pdf` `文書名_2of3.pdf` のような連番になります |

「解像度・品質を下げて再実行」の**削減方式**は、「原因ページのみ」（初期値。容量の大きい写真ページ等だけ画質を下げ、他のページの画質は保つ）と「全体を均等に」（全ページを少しずつ下げる）から選べます。

**用紙正規化**（初期値：オン） — 対応外の用紙サイズ・向きのページを自動修正します。B4・A3等の大きいページはA4に縮小して収め（縮小率は診断結果に表示）、A4より小さいページは拡大せずA4の中央に原寸のまま配置します。横向きページは、サービスが横向き非対応の場合に回転して縦向きに収めます。オフにすると、対応外サイズのページを含むPDFは変換できません（エラーになります）。

**変換レポートを出力先フォルダに保存する**（初期値：**オフ**） — 処理内容の記録（適用した方式・解像度など）をテキストファイルとして出力PDFと同じフォルダに保存します。必要な場合のみ有効にしてください。

## 3.5 プレビューの見かた

プレビュー欄の下部の表示で、いま見ているものが分かります。

| 表示 | 意味 |
|---|---|
| **変換イメージ：1 / 3 ページ目** | 変換前。現在の処理内容で変換した場合の**見込み**を表示中 |
| **変換結果：1 / 3 ページ目** | 変換後。実際に出力されたPDF**そのもの**を表示中 |

処理内容（圧縮方式・ディザ方式など）を変えると、変換イメージが自動で更新されます。変換完了後は変換結果の表示に切り替わり、自動調整（画質低下等）があった場合もその結果を確認できます。処理内容を変更するか別のファイルを選ぶと、変換イメージの表示に戻ります。分割して出力された場合、プレビューに表示されるのは最初のファイルです。残りは「出力フォルダを開く」からご確認ください。

ページの切り替えは、サムネイルのクリックのほか、PageUp・PageDownキー（前後のページ）、Home・Endキー（先頭・末尾）、拡大表示の上でのマウスホイールでも行えます。

## 3.6 出力ファイルの指定

出力ファイル名は自動で決まります（初期設定：入力ファイルと同じフォルダに「入力ファイル名＋`_fax`」で保存。例：`契約書.pdf` → `契約書_fax.pdf`。複数ファイル入力時は1件目〔一番上〕の入力ファイル名がもとになります）。「出力先...」ボタンで保存先・ファイル名を変更できます（現在のファイル名があらかじめ入力された状態でダイアログが開きます）。この変更はその変換限りで、次のファイルを選ぶと初期設定に戻ります。

出力先に同名ファイルがある場合は、変換実行時に上書き確認が表示されます。**「分割して再実行」で実際に分割された場合**、指定した名前は分割ファイルのもとになる名前として使われます（`指定名_1of3.pdf` 等）。指定した名前そのもののファイルは作られません。

# 第4章 設定

画面上部のメニュー「設定」から開きます。

## 4.1 FAXサービスを変更

初回起動時と同じ選択画面が開きます。サービスを切り替えると、制約値（容量上限・対応用紙）と診断結果が新しいサービスに合わせて更新されます。

## 4.2 変換の既定設定

毎回の変換の初期値をまとめて設定できます。設定項目は、出力先（入力ファイルと同じフォルダ／固定フォルダ）と出力ファイル名の方針、および圧縮方式・ディザ方式・JPEG品質・容量超過時の処理方式・削減方式・用紙正規化・変換レポートの各初期値です。

メイン画面で変更した処理内容は**その変換限り**で、次のファイルを選ぶとここで設定した既定値に戻ります（共有PCでも、誰が使っても同じ初期状態から始まるためです）。

## 4.3 複数PCで設定を揃える

設定ファイル `%APPDATA%\VA_FAX\settings.json` を他のPCの同じ場所へコピーすると、FAXサービスの選択と既定設定を一括で配布できます（Macでは、ホームの `.va_fax` フォルダにあります）。

# 第5章 こんなときは（トラブルと対処）

| 症状・メッセージ | 対処 |
|---|---|
| 起動しても画面がなかなか出ない | 正常です。onefile形式のため起動に数秒〜十数秒かかります |
| 「WindowsによってPCが保護されました」 | 「詳細情報」→「実行」を選択（2.2参照） |
| 「パスワードで保護されています」 | 暗号化PDFは変換できません。PDFのパスワードを解除してからやり直してください |
| 「入力ファイル「〇〇」を処理できませんでした」 | 複数入力のうち、表示されたファイルが暗号化されているか破損しています。該当の行をDeleteキーで削除するか、修正したファイルに差し替えてください |
| 「ページ数上限を超えています」 | サービスのページ数上限（秒速FAX送信=10ページ等）を超えています。ファイルを分けてから変換してください |
| 「対応外サイズのページが含まれるため送信できません」 | 用紙正規化がオフになっています。処理内容の「用紙正規化」にチェックを入れてください |
| 「すべてのページを最小設定まで縮小しても…下回りませんでした」 | 画質を最大まで下げても容量上限に収まりません。ディザ方式を「単純閾値」にする、グレースケールを試す、容量超過時の処理方式を「分割して再実行」にする、のいずれかをお試しください |
| 「分割後の出力ファイルが既に存在します」 | 前回の分割ファイル（`_1of3` 等）が残っています。移動・削除するか、出力ファイル名を変更してください |
| 「出力先のフォルダが見つかりません」 | 固定フォルダ（共有フォルダ等）に接続できていません。接続を確認するか、既定設定の出力先を見直してください |
| 「入力ファイルを読み込めませんでした」 | ファイルが移動・削除されていないか、他のアプリで開かれていないか確認してください |
| 受信側で文字がつぶれて読めない | 元のPDFの文字が小さすぎる可能性があります。容量超過時の処理方式を「分割して再実行」にすると、画質を下げずに送信できます |
