# 第1章 ツールの概要

## 1.1 これは何をするツールか

**VA FAX**は、インターネットFAXサービスで送るPDFの準備を、このツールだけで済ませるためのツールです。標準対応のMOT/FAXでは「A4・モノクロ・3MB以内」という送信条件がありますが、Wordから出力したPDFやスキャンした資料をそのまま送ろうとすると、「容量オーバーで送れない」「B4の資料が混ざっていて弾かれる」といった手戻りが起こりがちです。VA FAXは、ふつうのPDF編集アプリと同じようにファイルを開いてページを整え、保存すると、送信条件に合う形に変換して保存します。

- **ページの編集**：送信票（送付状）と本文を1つにまとめる、要らないページを削除する、順番を入れ替える、向きの違うページを回す、といった作業を、サムネイルの上で行えます（第3章3.4参照）
- **送付書（兼受領書）の作成**：訴訟で相手方に書面をFAXで直送するときの送付書を、このツールの中で作って先頭に入れられます。書類の一覧は、追加したファイルの名前から自動で作ります（VA mintsの「甲001 売買契約書」の形の名前は「甲第1号証」と書きます。3.9参照）
- **ページ番号**：保存する各ページの上端に「1/12」の形で通し番号を入れ、受け手が全ページ届いたかを確かめられるようにします（3.5参照）
- **画像の取り込み**：スマートフォンで撮った写真やスキャンした画像（JPEG・PNG）を、ページとして入れられます
- **全ページの画像化**：テキストデータ付きPDFで起こりうるフォントの置き換わり・送信失敗を、全ページを画像に変換することで構造的に回避します
- **用紙の正規化**：対応外サイズ（B4・A3等）のページをA4に収めます（縦横比は維持）
- **モノクロ化と圧縮**：FAXで最も一般的な白黒2値（G4圧縮）へ変換します。写真の多い資料向けにグレースケール（JPEG圧縮）も選べます。画像にせずそのまま保存する「何もしない」も選べます
- **容量上限への自動対処**：上限を超える場合、「解像度・品質を下げて再実行」（送信回数を増やさない）または「分割して再実行」（画質を下げない）のどちらかで自動調整します

**VA FAXが行うのはPDFの準備までです。** FAXの送信操作は、保存したPDFをお使いのインターネットFAXサービスの画面でアップロードして行ってください。

## 1.2 対応FAXサービス

送信条件（容量上限・対応用紙等）はサービスごとに異なるため、VA FAXは「サービスプロファイル」として切り替えられる仕組みになっています。次のプロファイルを同梱しています。

| サービス | 備考 |
|---|---|
| MOT/FAX（標準） | 公式仕様に基づく |
| MOVFAX | 公式仕様に基づく |
| メッセージプラス | 公式仕様に基づく |
| 秒速FAX送信 | 公式仕様に基づく |
| eFax | 容量上限（合計1MB）は参考値（公式未確認） |
| jFax | 容量上限（合計1MB）は参考値（公式未確認） |
| カスタム | お使いのサービスの公表仕様を入力して利用 |

各プロファイルの制約値は、いずれもサービス各社が公表している仕様に基づくものです（実際のFAX送信による動作検証は行っていません）。**どのサービスをお使いの場合も、初回はご自身のFAX番号宛にテスト送信して仕上がりをご確認ください。** 特にeFax・jFaxは容量上限が公式未確認の参考値のため、画面上にも同じ注意が表示されます。

## 1.3 安全性に関する設計方針

法律事務所等での利用を想定し、文書の秘密が外部に出ない設計としています。

- **完全ローカル動作**：いかなる処理段階でも外部ネットワーク通信を行いません。クラウドAPI・外部変換サービス・利用状況の送信・自動アップデート確認、いずれも実装していません。文書の内容がお使いのパソコンの外部に送信されることはありません。
- **文書情報を保存しない**：ページの編集や変換の途中のデータはすべてメモリ内で処理し、一時ファイルを作りません。ツールが設定として保存するのは、最後にファイルを開いたフォルダの場所・ウィンドウの大きさ等の画面状態と、送付書の送信者（事務所名・住所・電話・FAX・弁護士名）のみで、開いたファイルの名前・内容・履歴は保存しません（「最近使ったファイル」の一覧もありません）。送付書を入れた文書を保存したときだけ、その送付書の入力（宛先・事件・書類の一覧など）を、保存したPDFと同じフォルダの「FAX送付書データ」フォルダに保存します（3.9参照）。
- **文書のプロパティ情報も引き継がない**：二値化・グレースケールで保存したPDFは、ページ画像から新しく組み立てるため、元のPDFに埋め込まれた作成者名・タイトル・作成アプリ等のメタデータは含まれません（含まれるのは、VA FAXで作ったことを示す印だけです）。圧縮方式を「何もしない」にしたときは、ページをそのまま写すため、この限りではありません。
- **ログにもファイル名を残さない**：不具合調査用のログには技術情報（ページ番号・解像度・エラー種別等）のみを記録し、ファイル名・パスは記録しません。
- **保存するまでファイルを書き換えない**：ページの編集は、保存するまで画面の上だけで行われます。［保存］では、毎回、保存する場所と名前を指定します。名前の初めの値は「元の名前_fax.pdf」なので、そのまま保存すれば元のファイルは残ります。元のファイルと同じ名前を選んだときは、置き換えてよいかの確認が出ます（3.3参照）。ページの材料として追加したファイルは、変更しません。
- **保存の途中で失敗しても、元のファイルを壊さない**：保存は、同じフォルダに一時的な名前で書き終えてから、目的の名前に置き換えます。

# 第2章 導入方法

## 2.1 配布物の構成

本ツールは、次のファイル一式で構成されています。

| ファイル | 内容 |
|---|---|
| `VA_FAX.exe` | 実行ファイル本体（Python環境不要。これだけで動作します） |
| `README.md` | 利用者向け説明（VBAアセット掲載文と同一） |
| `VA_FAX_操作マニュアル_Ver210.pdf` | 本マニュアル |
| `LICENSE.txt` | ライセンス条文（MIT License） |
| `THIRD_PARTY_NOTICES.txt` | 本ツールが使っている部品（Python・PDFの処理の部品等）のライセンスの表示 |
| `source/` | ソースコード一式（Python。改変・再配布はライセンス条件の範囲内で自由） |

## 2.2 起動方法

1. `VA_FAX.exe` を任意のフォルダ（デスクトップ等）に置き、ダブルクリックして起動します。インストール・Python環境は不要です。
2. **起動に数秒〜十数秒かかることがあります。** 必要なファイルを1つにまとめた形式（onefile）のため、起動のたびに内部で展開処理を行います。画面が出るまでお待ちください。
3. Windows Defender SmartScreen等により「WindowsによってPCが保護されました」と警告が表示される場合がありますが、これは未署名の実行ファイルに一般的に表示されるものです。「詳細情報」をクリックし、「実行」を選択してください。内容にご不安がある場合は、`source/` フォルダ内のソースコードをご確認いただくか、ご自身の環境でビルドし直してご利用ください。

ウィンドウの大きさ・位置（最大化していたかどうかを含む）は、閉じたときのものを覚えていて、次に起動したときに元に戻ります。

## 2.3 動作環境

Windows 10 / 11（64bit）を想定しています（法律事務所の一般的なPC環境に合わせています）。

Macでは、同梱のソースコード（`source/` フォルダ。GitHubの VBA-Assets/VA_FAX と同じもの）から動かせます（動作は保証しません。Macの実機では動作を確かめていません）。Mac用の実行ファイルは配っていません。Python 3（Tkの入ったもの。python.orgのmacOS用インストーラーのPythonには入っています）を入れ、ターミナルで `source` フォルダに移って、`python3 -m pip install -r requirements.txt` で必要な部品を入れてから、`python3 src/main.py` で起動します。

- **標準のMOT/FAXはMacから使えません。** MOT/FAXの公表仕様では、利用できる機器がWindows PC・Android・iPhoneで、Macは含まれていません。Macでは、お使いのサービス（MOVFAX・メッセージプラス・秒速FAX送信など）を選んでください。そのサービスをMacから使えるかは、各サービスの案内でご確認ください。
- 設定・追加プロファイル・ログは、`%APPDATA%\VA_FAX` ではなく、ホームの `.va_fax` フォルダに置かれます。
- Ctrlのキー（Ctrl+O・Ctrl+S・Ctrl+Z など）は、⌘でも効きます。右クリックは、2本指のクリックか、Controlキーを押しながらのクリックでも行えます。

## 2.4 初回起動：FAXサービスの選択

はじめての起動時に「お使いのFAXサービスを選んでください」という画面が表示されます。契約中のサービスを選んで「決定」を押してください。ここで選んだサービスの制約（容量上限・対応用紙）に合わせて変換が行われます。あとから変更する場合は、メニューの「ファイル」→「オプション...」の「FAXサービス」のタブです（4.1参照）。

「カスタム」を選ぶと、サービス名・最大ファイルサイズ・ページ数上限・対応用紙サイズ等を自分で入力できます（一覧にないサービスをお使いの場合）。

# 第3章 基本的な使い方

## 3.1 画面の見かた

メイン画面は、上部の**リボン**と、その下の左右2つの領域に分かれています（左右の境界はドラッグで動かせます）。ウィンドウの題名には、開いているファイルの名前が `送信票.pdf - VA FAX` のように表示されます。まだ保存していない作業があるときは、名前の前に「＊」が付き、リボンの［保存］が青い枠で囲まれます（`＊送信票.pdf - VA FAX`）。ふつうのPDFを開いた直後も、まだ送る形（二値化など）にしていないので「＊」が付きます。保存すると消えます。「何もしない」でページ番号もオフ、ページも編集していないときは、保存しても同じものしかできないので、付きません。

**上部：リボン** — Word等と同じ形のボタンの並びで、操作に使うボタンがすべてここにあります。「ファイル」「ページ」「送付書」の3つの組に分かれています。

| 組 | ボタン | 説明 |
|---|---|---|
| ファイル | 新規作成 | ページのない新しい文書を作ります（3.3参照） |
| ファイル | 開く | PDFファイルを開きます（3.3参照） |
| ファイル | 保存 | 選んだ処理内容で変換して、場所と名前を指定して保存します（3.3参照） |
| ページ | 追加 | PDF・画像のページを、選んでいるページの後ろに入れます（3.4参照） |
| ページ | 削除 | 選んでいるページを取り除きます |
| ページ | 回転 | 押すとメニューが開き、「左に90°回転」「右に90°回転」「180°回転」から選びます |
| ページ | 元に戻す・やり直す | ページの編集を、1つずつ戻し、また進めます |
| 送付書 | 作成（編集） | 送付書（兼受領書）を作って、文書の先頭に入れます。作成済みのときは文字が「編集」になり、送付書を直せます（3.9参照） |

ボタンにマウスを重ねると、少し間をおいてそのボタンの説明が表示されます。押せないボタンでは、押せるようになる条件が表示されます。ウィンドウの幅が狭いときは、入りきらない組が次の段に折り返されます。

画面上部のメニューバーには、［ファイル］（新規作成・開く・保存・閉じる・オプション〔第4章〕・終了）と［ヘルプ］（3.8参照）があります。

**左側：プレビュー欄（ページの一覧）** — ページのサムネイル一覧と、選んでいるページの拡大表示です。サムネイルの下にはページ番号が出ます。サムネイルは、ページの選択・並べ替え・削除にも使います（3.4参照）。下部に「変換イメージ：1 / 3 ページ目」のような表示状態が出ます（3.6参照）。

**右側：操作欄（上から順に）**

| 項目 | 説明 |
|---|---|
| 対象サービス | 選択中のFAXサービスと制約値（例「MOT/FAX（上限3MB・A4）」） |
| 診断結果 | ページ数・用紙サイズ・カラーの有無・テキストの有無など。ページを編集するたびに更新されます |
| 処理内容の選択 | 圧縮方式などの変換設定（3.5参照） |
| 進捗バーと結果 | 保存の進み具合と、「保存しました：送信票.pdf（3ページ、120KB。上限 3MB）」のような、いちばん新しい結果 |

## 3.2 基本の流れ

1. リボンの**［開く］**で、送りたいPDFを開きます。送付書を付けて複数の書面を送るときは、**［新規作成］**で白紙から始め、［追加］で書面を入れることもできます（ウィンドウへのドラッグ＆ドロップでも開けます）
2. 送信票などのページを足すときは**［追加］**、要らないページは**［削除］**、向きの違うページは**［回転］**で整えます（3.4参照）。送付書をこのツールで作るときは、送るページをすべて入れてから、「送付書」の組の**［作成］**を押します（3.9参照）
3. **診断結果**と左側の**プレビュー**（変換後の見込み）を確認します
4. 必要なら**処理内容**を変更します（通常は初期設定のままで問題ありません）
5. **［保存］**を押し、保存する場所と名前を指定します（初めの値は「元の名前_fax.pdf」。開いたファイルに上書きするときは、同じ名前を選びます）

保存すると、プレビューが「保存した結果」（実際に保存した内容）に切り替わります。あとは保存したPDFをFAXサービスの画面でアップロードするだけです。

## 3.3 ファイルを開く・保存する

**新規作成**（Ctrl+N） — ページのない新しい文書を作ります。［追加］か、ファイルのドラッグ＆ドロップでページを入れ、必要なら送付書を作って（3.9参照）、［保存］します。題名は、保存するまで「新しい文書」です。保存の画面の名前と場所の初めの値は、初めに入れたファイルから決まります（例：`準備書面（1）.pdf` を初めに入れたら `準備書面（1）_fax.pdf`。送付書だけのときは `送付書_fax.pdf`）。ページを入れるまでは、［保存］は押せません。

**開く**（Ctrl+O） — PDFファイルを1つ選んで開きます。開いたファイルが、その文書の保存先になります。ファイルをウィンドウへドラッグ＆ドロップしても開けます（何も開いていないとき。複数のファイルを落とすと、1つ目を開き、残りをその後ろに追加します）。

**画像を開いたとき** — JPEG・PNGの画像を［開く］で選ぶと、名前のない新しい文書として開きます（画像のファイルをPDFで書き換えないため）。題名には、保存するときの名前の初めの値（「元の名前_fax.pdf」）が表示されます。

**保存**（Ctrl+S。リボンの大きいボタン。メニューでは［保存...］） — 選んだ処理内容（3.5参照）で変換して、保存の画面で指定した場所と名前に保存します。保存の画面には、初めに、開いたファイルの名前に「_fax」を付けた名前（例：`契約書.pdf` → `契約書_fax.pdf`）と、そのファイルのフォルダが入っています（付けるかどうかと、付ける文字は、［ファイル］→［オプション］で選べます。4.3参照）。以後は、指定したファイルがその文書の保存先になります。ページの材料として追加したファイルと同じ名前では保存できません（材料のファイルは書き換えません）。

- **開いたファイルに上書きするとき**は、保存の画面で、開いたファイルと同じ名前を選びます。置き換えてよいかの確認が出ます。二値化・グレースケールのときは、画像にしたもので置き換わり、元に戻せません。
- Ver.200 までの［保存］（上書き保存）と［名前を付けて保存］は、働きに差がないため、Ver.210 でこの［保存］1つにまとめました。あわせて、［開く］と働きに差がなくなった［コピーして開く］をなくしました（元のファイルを残すには、名前の初めの値のまま保存します）。

同じ文書をもう一度保存するときは、前に保存した結果ではなく、開いたときのページから作り直します（変換を重ねて画質が落ちることはありません。処理内容を変えて保存し直すこともできます）。

**保存していないとき**（題名に「＊」があるとき） — 文書を閉じる・新規作成・別のファイルを開く・VA FAXを終了するときに、「「（名前）」を保存していません。保存しますか？」と尋ねます（［保存する］［保存しない］［キャンセル］）。PDFを開いて中身を見ただけのときも尋ねるので、送る形のファイルを作らないときは［保存しない］を選んでください。

**VA FAXで保存したファイルを開いたとき** — VA FAXで二値化・グレースケールにして保存したファイルを開くと、圧縮方式の初めの値が「何もしない」になります（もう一度変換して画質が落ちることを防ぐため）。ページを入れ替えるだけなら、そのまま保存してください。

## 3.4 ページの編集

ページの編集は、保存するまで画面の上だけで行われ、ファイルは変わりません。

**選択** — 削除・回転などの操作は、先に対象のページをサムネイルで選んでから行います。サムネイルをクリックすると、そのページが青い枠で囲まれ、これが操作の対象です。複数のページを選ぶときは、**Shift**キーを押しながらクリック（範囲）するか、**Ctrl**キーを押しながらクリック（1ページずつ）します。すべて選ぶには**Ctrl+A**を押します。**PageUp／PageDown**、**Home／End**でも選択が移動します（**Shift**キーを押しながら**PageUp／PageDown**を押すと、範囲が広がります）。

**追加** — リボンの**［追加］**で、PDF・画像（JPEG・PNG）のファイルを選びます（複数選べます）。そのページが、選んでいるページの後ろ（何も選んでいないときは末尾）に入ります。ファイルを**サムネイルの間へドラッグ＆ドロップ**すると、落とした位置に入ります（入る位置が青い線で表示されます）。追加したページは、選択した状態になります。一度に10件を超えて追加しようとした場合は、確認の画面が表示されます。

- 画像は、1枚につき1ページになります。画像に解像度の情報があり、その実寸が用紙（A4等）に収まるときは実寸のページに、それ以外は用紙に収まる大きさのページになります。スマートフォンの写真の向きの情報も反映します。写真の位置情報等は、保存するPDFに入りません。

**削除** — ページを選んで、リボンの**［削除］**か、**Delete**キーを押します。サムネイルを**欄の外へドラッグして放す**方法でも削除できます（マウスカーソルがゴミ箱の絵に変わったところで放してください）。最後の1ページは削除できません。

**並べ替え** — 動かしたいページのサムネイルをマウスでつかんで、入れたい位置まで動かして離します（つかんだ時点でそのページが選択されるので、あらかじめクリックしておく必要はありません）。動かしている間、入る位置が青い線で表示されます。複数のページを選んでからその中をつかむと、選んだページがまとめて移動します。ポインタを欄の上端・下端に近づけると、一覧が自動でスクロールします。途中でやめたいときは、マウスのボタンを離す前に**Esc**キーを押します。

**回転** — ページを選んで、リボンの**［回転］**を押し、開いたメニューから「左に90°回転」「右に90°回転」「180°回転」を選びます。横倒しのページや逆さまのページを直すときに使います。

**元に戻す・やり直す** — ページの編集（追加・削除・並べ替え・回転）は、**Ctrl+Z**（元に戻す）で1つずつ戻し、**Ctrl+Y**（やり直す）でまた進められます。保存した後も、文書を閉じるまでは戻せます。処理内容の選択（圧縮方式など）の変更は、元に戻すの対象になりません。

**右クリックメニュー** — サムネイルを右クリックすると、ページの各コマンド（追加・削除・左に90°回転・右に90°回転・180°回転・元に戻す・やり直す）のメニューが出ます。選んでいないページの上で右クリックすると、そのページだけを選んでからメニューが出ます。

**主なキー操作**

| キー | 操作 |
|---|---|
| Ctrl+N | 新規作成 |
| Ctrl+O | 開く |
| Ctrl+S | 保存（Ctrl+Shift+S でも同じ） |
| Ctrl+Z ／ Ctrl+Y | 元に戻す ／ やり直す |
| Delete | 選んでいるページを削除（サムネイルの欄を操作した後） |
| Ctrl+A | すべてのページを選ぶ（同上） |
| PageUp・PageDown・Home・End | 前後・先頭・末尾のページへ（同上） |

## 3.5 処理内容の選択

［保存］のときに行う処理は、画面の右側で、チェックボックス・ラジオボタンで内容を確認・選択します。選択肢の副作用（「カラー・階調情報が失われます」等）は画面上にも表示されます。ファイルを開くたびに、処理内容の既定値（4.2参照）に戻ります。

**圧縮方式**

| 選択肢 | 説明 |
|---|---|
| **二値化（白黒・G4圧縮）**（初期値） | 白黒2値に変換します。カラー・階調情報は失われますが、FAXで最も一般的な原稿形式で、ファイルも小さくなります |
| **グレースケール（JPEG圧縮）** | 濃淡を残します。写真・図版中心の資料向け。ただしサービス側で黒つぶれ・白飛びが起こる場合があるため、実際に送信して仕上がりをご確認ください |
| **何もしない** | ページを画像にせず、そのまま保存します（文字データ・カラーが残ります）。既に送信用の形式になっているファイルのページを入れ替えるだけのときなどに使います。サービスによっては送信できない場合があります |

二値化の**ディザ方式**は「自動」（初期値）のままにしておくと、ページ内容から最適な方式を1ページずつ自動選択します（文字・線画のページには単純閾値、写真・グラデーションのページには誤差拡散）。手動で「単純閾値」「誤差拡散」に固定することもできます。グレースケールの**JPEG品質**は高・中（初期値）・低から選択します。

**容量超過時の処理方式** — 保存するファイルがサービスの容量上限を超えた場合の対処方法です。

| 選択肢 | 説明 |
|---|---|
| **解像度・品質を下げて再実行**（初期値） | 画質を段階的に下げて1ファイルに収めます。送信回数を増やさずに済みます |
| **分割して再実行** | 画質を下げずに、複数のPDFに分割します（3.7参照） |
| **何もしない** | 上限を超えていても、そのまま保存します。保存の後に、大きさと上限を知らせます |

「解像度・品質を下げて再実行」の**削減方式**は、「原因ページのみ」（初期値。容量の大きい写真ページ等だけ画質を下げ、他のページの画質は保つ）と「全体を均等に」（全ページを少しずつ下げる）から選べます。

**用紙正規化**（初期値：オン） — 対応外の用紙サイズ・向きのページを自動修正します。B4・A3等の大きいページはA4に縮小して収め（縮小率は診断結果に表示）、A4より小さいページは拡大せずA4の中央に原寸のまま配置します。横向きページは、サービスが横向き非対応の場合に回転して縦向きに収めます。オフにすると、対応外サイズのページを含む文書は保存できません（エラーになります）。［ファイル］→［オプション］の「処理内容の既定値」でオフにすると、この項目は画面に出なくなり、用紙正規化を行いません（4.2参照）。

**ページ番号を入れる**（初期値：オン） — 保存する各ページの上端の中央（用紙の端から5mm）に、「1/12」の形で通し番号を入れます。受け手は、送付書の「本書を含め12枚」と照らして、全ページが届いたか、抜けや順番違いがないかを確かめられます。送付書（3.9参照）も1ページ目として数えます。容量を超えて分割したときも、ファイルをまたいだ通し番号になります。番号の下地は白く塗るので、ページの上端に文字があっても読めます（VA FAXで番号を入れて保存したファイルに入れ直したときは、前の番号が隠れます）。番号はプレビューでも確かめられます。圧縮方式が「何もしない」のときも入れられます（ページの中身はそのままで、番号だけを重ねます。VA FAXで保存したファイルのページを入れ替えたときに、画質を落とさずに番号を付け直せます）。［ファイル］→［オプション］の「処理内容の既定値」でオフにすると、この項目は画面に出なくなり、番号を入れません（4.2参照）。

**圧縮方式が「何もしない」のとき** — ページを画像にしないので、「解像度・品質を下げて再実行」と用紙正規化は効きません。この2つは選べない状態になり、その理由が画面に表示されます（容量超過時の処理方式が「解像度・品質を下げて再実行」だったときは「何もしない」に切り替わり、圧縮方式を戻すと元に戻ります）。また、ページ数の上限や対応外の用紙サイズがあっても保存は止めず、保存の後に、送信の制約に合っていない点を知らせます。

## 3.6 プレビューの見かた

プレビュー欄の下部の表示で、いま見ているものが分かります。

| 表示 | 意味 |
|---|---|
| **変換イメージ：1 / 3 ページ目** | 保存の前。現在の処理内容で変換した場合の**見込み**を表示中 |
| **そのままの表示（画像にしません）：1 / 3 ページ目** | 圧縮方式が「何もしない」のとき。ページをそのまま表示中 |
| **保存した結果：1 / 3 ページ目** | 保存の後。実際に保存したPDF**そのもの**を表示中 |

処理内容（圧縮方式・ディザ方式など）を変えると、変換イメージが自動で更新されます。保存の後は保存した結果の表示に切り替わり、自動調整（画質低下等）があった場合もその結果を確認できます。処理内容を変更するかページを編集すると、変換イメージの表示に戻ります。

拡大表示するページの切り替えは、サムネイルのクリックのほか、PageUp・PageDownキー（前後のページ）、Home・Endキー（先頭・末尾）、拡大表示の上でのマウスホイールでも行えます。

## 3.7 容量を超えて分割されたとき

容量超過時の処理方式が「分割して再実行」で、実際に分割が起きた場合は、保存先と同じフォルダに `文書名_1of3.pdf` `文書名_2of3.pdf` `文書名_3of3.pdf` のような連番のファイルを作ります。

- **保存先のファイル（開いたファイル）そのものは書き換えません。** そのため、文書は未保存のままになります（題名の「＊」は消えません）。
- 完了のお知らせに、作ったファイルの名前が表示されます。［フォルダを開く］で、その場所を開けます。プレビューには、最初のファイルが表示されます。
- 同じ名前の分割ファイルが既にあるときは、保存せずにエラーになります。前のファイルを移動・削除するか、［保存］で別の名前を指定してください。

## 3.8 ヘルプメニューと診断情報

画面上部の［ヘルプ］メニューから、次の操作ができます。

- **診断情報をコピー**：ツールの版・OS・対象サービスの制約値・設定の数値・文書のページ数・起きたエラーの型と場所（ファイル名・行・関数名）だけをまとめた文を、クリップボードにコピーします。**開いた・保存したファイルの名前、ファイルやフォルダの場所、エラーメッセージの本文など、文書の内容につながる情報は含まれません。** 不具合をAIや作成者に相談するときは、この診断情報を使ってください（中身は入りません）。渡す前に、メモ帳などに貼り付けて内容を確かめることもできます。
- **VA FAX について**：ツールの名前と版を表示します。

## 3.9 送付書（兼受領書）を作る

訴訟で相手方に書面をFAXで直送するとき（民事訴訟規則47条）の送付書を、このツールの中で作れます。作った送付書は、文書の先頭のページになり、ほかのページと同じく、処理内容（二値化など）に従って保存されます。法令や裁判所が定めた様式はないため、実務でよく使われる項目で作ります。

**初めに一度だけ：送信者の入力** — 画面上部のメニュー「ファイル」→「オプション...」の「送付書」のタブで、事務所名・住所・電話番号・FAX番号・弁護士名を入力して［保存］を押します（4.4参照）。空の項目は、送付書に書きません。

**作り方**

1. 送る書面（準備書面・証拠説明書・書証など）を、送る順に入れます。［新規作成］で白紙から始めて［追加］で入れるか、1つ目を［開く］で開いて、残りを［追加］で入れます
2. リボンの「送付書」の組の**［作成］**を押すと、入力の画面（題名「送付書」）が開きます
3. 宛先（裁判所の係と、相手方の代理人）、送信者の肩書（例：原告訴訟代理人弁護士）、事件番号などを確かめて、**［OK］**を押します

送付書が文書の先頭に入ります（プレビューで確かめてください）。送付書を入れると、ボタンの文字が**［編集］**に変わります。直すときは、［編集］を押すか、**送付書のページ（サムネイル又は拡大表示）をダブルクリック**して入力の画面を開き、［OK］を押すと、直した送付書に差し替わります。送付書を入れる・差し替えるのも、ページの編集の1つとして、元に戻せます（Ctrl+Z）。

**入力の画面の項目**

| 項目 | 説明 |
|---|---|
| 送信日 | 初めは今日の日付（和暦） |
| 宛先 | 裁判所（「御中」を付けます）と、相手方（敬称は「殿」「先生」「様」から選びます）。それぞれFAX番号を書けます。裁判所の欄が空なら、裁判所の宛先は書きません |
| 送信者 | 肩書を入力します。事務所名などは、オプションで入力したものを使います |
| 事件 | 事件番号・事件名・当事者。空の項目は書きません |
| 送付する書類 | 書類の名前と枚数。**初めは、文書に入れたファイルの名前から作ります**（下の説明）。行を直す・足すことができます。空の行は書きません。［ファイルから作り直す］で、いまの文書から作り直します |
| 通信欄 | 次回期日の連絡など、自由に書けます。何も書かないときは、送付書に通信欄の枠を書きません |
| 受領書の欄を付ける | 初めはオン。オンのときは、表題が「送付書（兼受領書）」になり、下半分に、相手方が記名押印して返送する受領書の欄が付きます（受領書は、相手方が送信者と裁判所にFAXで返します。民事訴訟規則47条の2第3項）。訴訟以外の送付では、オフにします |

**書類の一覧の作り方** — 文書に入れたファイルごとに1行を作り、枚数は、いまの文書に残っているそのファイルのページ数にします（送付書自身は数えません）。VA mintsの命名による証拠のファイル（`甲001 売買契約書.pdf`、枝番の `甲005-2 写真.pdf` など）は「甲第1号証」「甲第5号証の2」と書き、番号が続くものは「甲第1号証〜第3号証」「甲第5号証の1〜3」のように1行にまとめます。それ以外のファイルは、ファイルの名前（拡張子を除く）をそのまま書きます。

**送信枚数** — 送付書には「送信枚数 本書を含め N 枚」と書きます。N は、送付書を含めた文書のページ数です。送付書を作った後にページを追加・削除して、送信枚数とページ数が合わなくなったときは、保存するときに知らせます（［送付書を直す］［このまま保存］［キャンセル］）。

**入力の初めの値と保存** — 送付書を入れた文書を保存すると、その入力（宛先・事件・書類の一覧・通信欄など。事務所名などの送信者は除く）を、保存したPDFと同じフォルダの**「FAX送付書データ」フォルダ**に、`（保存したPDFの名前）.json` として保存します。次の場合に、入力の画面の初めの値として使います。

- そのPDFをVA FAXで開いて［編集］を押したとき：保存したときの入力（1ページ目を送付書とみなし、差し替えます）
- 同じフォルダで、別の文書の送付書を作るとき：そのフォルダでいちばん新しい入力の、宛先・事件・肩書（同じ事件の書面を続けて送るときに、入力の手間が減ります）
- どちらもなく、VA mintsで証拠説明書を作ったフォルダのファイルを入れたとき：VA mintsの証拠説明書の入力（`証拠説明書データ\証拠説明書.json`）の、裁判所・事件番号・提出者（肩書）

「FAX送付書データ」フォルダには、宛先や事件の情報が入ります。FAXサービスにアップロードするのは、保存したPDFだけです。フォルダごと人に渡すときは、このフォルダを含めてよいかを確かめてください。

# 第4章 設定（オプション）

画面上部のメニュー「ファイル」→「オプション...」で開く画面で、設定をまとめて変えられます。画面は「保存」「処理内容の既定値」「FAXサービス」「送付書」の4つのタブに分かれています。［保存］を押すと、すべてのタブの内容が保存されます（［キャンセル］では何も変わりません）。保存の処理の途中は開けません。

Ver.130までの［設定］メニュー（FAXサービスを変更・変換の既定設定）は、この画面にまとめました。

## 4.1 FAXサービス

初回起動時と同じ並びで、お使いのサービスを選びます。サービスを切り替えると、制約値（容量上限・対応用紙）と診断結果が新しいサービスに合わせて更新されます。

ほかのサービスから「カスタム」に替えるときは、［保存］を押したときに、カスタムの内容（サービス名・最大ファイルサイズ・ページ数上限・対応用紙サイズ等）を入力する画面が開きます。カスタムを選んでいる間は、［カスタムの内容を入力...］で内容を変えられます。

## 4.2 処理内容の既定値

ファイルを開いたときの処理内容の初期値をまとめて設定できます。設定項目は、圧縮方式（二値化・グレースケール・何もしない）・ディザ方式・JPEG品質・容量超過時の処理方式（解像度・品質を下げて再実行・分割して再実行・何もしない）・削減方式・用紙正規化・ページ番号の各初期値です。用紙正規化・ページ番号をオフにすると、メイン画面の処理内容の選択にその項目が出なくなり、その処理を行いません（使わない事務所向け）。値を変えて保存すると、開いている文書の処理内容も新しい既定値に戻ります。

メイン画面で変更した処理内容は**その文書限り**で、次にファイルを開くとここで設定した既定値に戻ります（共有PCでも、誰が使っても同じ初期状態から始まるためです）。

Ver.130までの「出力先」「出力ファイル名」「変換レポート」の項目はなくなりました（保存先は、［保存］で指定した場所です）。

## 4.3 保存

| 項目 | 説明 |
|---|---|
| ［保存］の画面に初めに入るファイル名に、次の文字を付ける（初期値：オン、付ける文字は「_fax」） | ［保存］の画面に初めに入る名前と、画像を開いた文書の名前に、この文字を付けます（`契約書.pdf` → `契約書_fax.pdf`）。付ける文字は「-fax」「_送信用」などに変えられます（20文字まで。`\ / : * ? " < > |` は使えません）。オフにすると、開いたファイルと同じ名前（拡張子は .pdf）になります。どちらの場合も、保存の画面で名前を変えられます |
| 保存の後に、保存したフォルダを開く（初期値：オフ） | 保存の後に、保存したフォルダをエクスプローラーで開きます。FAXサービスの画面へアップロードするときに、ファイルを探す手間が減ります |

## 4.4 送付書

送付書（3.9参照）の送信者の欄に書く、事務所名・住所（2行まで）・電話番号・FAX番号・弁護士名を入力します。空の項目は、送付書に書きません。肩書（例：原告訴訟代理人弁護士）は、事件ごとに違うので、送付書を作るときに入力します。

## 4.5 複数PCで設定を揃える

設定ファイル `%APPDATA%\VA_FAX\settings.json` を他のPCの同じ場所へコピーすると、オプションの内容（FAXサービスの選択・処理内容の既定値・保存の設定・送付書の送信者）を一括で配布できます（Macでは、ホームの `.va_fax` フォルダにあります）。

| 「（ファイル名）を処理できませんでした」 | 表示されたファイルが、暗号化・破損しているか、PDF・JPEG・PNG以外の形式です。修正したファイルでやり直してください |
| ［保存］が押せない | ファイルを開いていないか、診断が終わっていません。診断結果が表示されるまでお待ちください |
| ［削除］が押せない | ページを選んでいないか、すべてのページを選んでいます（最後の1ページは削除できません） |
| 「ページ数上限を超えています」 | サービスのページ数上限（秒速FAX送信=10ページ等）を超えています。要らないページを削除するか、文書を分けて保存してください |
| 「対応外サイズのページが含まれるため送信できません」 | 用紙正規化がオフになっています。処理内容の「用紙正規化」にチェックを入れてください |
| 「すべてのページを最小設定まで縮小しても…下回りませんでした」 | 画質を最大まで下げても容量上限に収まりません。ディザ方式を「単純閾値」にする、グレースケールを試す、容量超過時の処理方式を「分割して再実行」にする、のいずれかをお試しください |
| 「分割してできるファイルと同じ名前のファイルが、既にあります」 | 前回の分割ファイル（`_1of3` 等）が残っています。移動・削除するか、［保存］で別の名前を指定してください |
| 「ファイルを書き込めませんでした」 | 保存先のフォルダの権限や空き容量、ファイルが他のアプリ（PDFの閲覧ソフト等）で開かれていないかを確認してください。元のファイルは壊れていません |
| 保存の後に「送信の制約に合っていません」と表示された | 圧縮方式または容量超過時の処理方式が「何もしない」のため、制約に合わないまま保存されています。送信できない見込みのときは、二値化・グレースケール、又は「解像度・品質を下げて再実行」で保存し直してください |
| 受信側で文字がつぶれて読めない | 元のPDFの文字が小さすぎる可能性があります。容量超過時の処理方式を「分割して再実行」にすると、画質を下げずに送信できます |

# 第6章 AIを使ってツールを改造するとき

本ツールはソースコードを同梱しており、事務所独自の機能をAI（コーディング支援のAI）で追加することもできます。その場合は、次の手順で、**AIが実データ（依頼者・事件の情報）に届かない場所で作業させてください。**

## 6.1 なぜ注意が必要か

AIが読んだファイルや画面は、AIの会社のサーバーに送られます。依頼者の情報をAIに読ませると、守秘義務の点で問題になり得ます。AIは作業の途中で、思わぬファイルを開くことがあります。そのため、「気をつけて使う」だけでは防げません。AIが実データに届かない場所で作業させてください。

## 6.2 手順1　AI専用のWindowsユーザーを作る

- ［設定］→［アカウント］→［他のユーザー］で、AIの作業に使うユーザーを作ります。管理者にはせず、標準ユーザーにします。
- このユーザーでは、事務所のOneDrive・SharePointにサインインしません。共有フォルダ・ネットワークドライブ・暗号化した仮想ドライブにもつなぎません。
- 作ったら、このユーザーでエクスプローラーを開き、事務所の共有データの場所が見えないこと、開けないことを確かめます。見える場合は、そのフォルダのアクセス許可からこのユーザーを外してください。
- 別のPCをAIの作業に使えるなら、さらに確実です。

## 6.3 手順2　このユーザーで、ソースと試用データだけを使って作業する

- ソースは、このユーザーで新しく手に入れます。サイトから配布物（zip）をダウンロードし直し、`source/` フォルダのソースコードを使います（GitHubのVBA-Assets/VA_FAXから取ってもかまいません）。ふだんのユーザーのフォルダから写さないでください。
- 設定ファイル（`%APPDATA%` の下のVA_FAXフォルダにあるもの）は、この専用ユーザーで新しく作られたものを使います。ふだんの設定ファイルを写さないでください（最後に開いたフォルダの場所など、フォルダの名前に依頼者名が入ることがあります）。
- 試すPDFは、架空の文書か、付属のスクリプト（`source/samples/make_samples.py`）で作る架空のサンプルPDFを使います。実際の事件の書類は使いません。
- 実データの中身を、AIに貼り付けたり、画面の写しで見せたりしないでください。
- 不具合をAIに相談するときは、［ヘルプ］→［診断情報をコピー］（3.8参照）を使います。診断情報には、版・設定の数値・件数やエラーの場所だけが入り、ファイルの名前や場所などの中身は入りません。

## 6.4 手順3　実データでの確認と入れ替えは、ふだんのユーザーで人が行う

- 改造してできた実行ファイルを、ふだんのユーザーに移します。
- まず実データの写しで試し、問題がなければ使い始めます（本ツールの［保存］は開いたファイルを書き換えるので、必ず写しで試してください）。
