# 第1章 VA FAX の概要

## 1.1 VA FAX とは

**VA FAX** は、インターネット FAX サービスで送る PDF の準備を、このツールだけで済ませるためのツールです。標準対応の MOT/FAX では「A4・モノクロ・3MB 以内」という送信条件がありますが、Word から出力した PDF やスキャンした資料をそのまま送ろうとすると、「容量オーバーで送れない」「B4 の資料が混ざっていて弾かれる」といった手戻りが起こりがちです。VA FAX は、ふつうの PDF 編集アプリと同じようにファイルを開いてページを整え、保存すると、送信条件に合う形に変換して保存します。

**VA FAX が行うのは PDF の準備までです。** FAX の送信操作は、保存した PDF をお使いのインターネット FAX サービスの画面でアップロードして行ってください。

## 1.2 主な機能

- **ページの編集**：送信票（送付状）と本文を1つにまとめる、要らないページを削除する、順番を入れ替える、向きの違うページを回す、といった作業を、サムネイルの上で行えます（3.5）
- **送付書（兼受領書）の作成**：訴訟で相手方に書面を FAX で直送するときの送付書を、VA FAX の中で作って先頭に入れられます。書類の一覧は、追加したファイルの名前から自動で作ります（VA mints の「甲001 売買契約書」の形の名前は「甲第1号証」と書きます。3.10）
- **ページ番号**：保存する各ページの上端に「1/12」の形で通し番号を入れ、受け手が全ページ届いたかを確かめられるようにします（3.6）
- **画像の取り込み**：スマートフォンで撮った写真やスキャンした画像（JPEG・PNG）を、ページとして入れられます
- **全ページの画像化**：テキストデータ付き PDF で起こりうるフォントの置き換わり・送信失敗を、全ページを画像に変換することで避けます
- **用紙の正規化**：対応外サイズ（B4・A3 など）のページを A4 に収めます（縦横比は保ちます）
- **モノクロ化と圧縮**：FAX で最も一般的な白黒2値（G4 圧縮）へ変換します。写真の多い資料向けにグレースケール（JPEG 圧縮）も選べます。画像にせずそのまま保存する「何もしない」も選べます
- **容量上限への自動対処**：上限を超える場合、「解像度・品質を下げて再実行」（送信回数を増やさない）または「分割して再実行」（画質を下げない）のどちらかで自動で調整します

**対応する FAX サービス** — 送信条件（容量上限・対応用紙など）はサービスごとに違うため、VA FAX は「サービスプロファイル」として切り替えられるようにしています。次のプロファイルを同梱しています。

| サービス | 備考 |
|---|---|
| MOT/FAX（標準） | 公式仕様に基づく |
| MOVFAX | 公式仕様に基づく |
| メッセージプラス | 公式仕様に基づく |
| 秒速FAX送信 | 公式仕様に基づく |
| eFax | 容量上限（合計 1MB）は参考値（公式未確認） |
| jFax | 容量上限（合計 1MB）は参考値（公式未確認） |
| カスタム | お使いのサービスの公表仕様を入力して使う |

各プロファイルの制約値は、いずれもサービス各社が公表している仕様に基づくものです（実際の FAX 送信による動作検証は行っていません）。**どのサービスをお使いの場合も、初回はご自身の FAX 番号宛にテスト送信して、仕上がりを確かめてください。** 特に eFax・jFax は容量上限が公式未確認の参考値のため、画面にも同じ注意を出します。

## 1.3 VA FAX の方針

法律事務所などでの利用を想定し、文書の秘密が外へ出ないように作っています。

- **外部と通信しません**：どの処理でも、ネットワークの通信を行いません。クラウドの API・外部の変換サービス・利用状況の送信・自動アップデートの確認は、いずれもありません。文書の内容が、お使いの PC の外へ送られることはありません。
- **文書の情報を保存しません**：ページの編集や変換の途中のデータは、すべてメモリの中で処理し、一時ファイルを作りません。開いたファイルの名前・内容・履歴は保存しません（「最近使ったファイル」の一覧もありません）。保存されるものは、1.4 のとおりです。
- **文書のプロパティの情報も引き継ぎません**：二値化・グレースケールで保存した PDF は、ページの画像から新しく組み立てるため、元の PDF に埋め込まれた作成者名・タイトル・作成アプリなどの情報は入りません（入るのは、VA FAX で作ったことを示す印だけです）。圧縮方式を「何もしない」にしたときは、ページをそのまま写すため、この限りではありません。
- **保存するまでファイルを書き換えません**：ページの編集は、保存するまで画面の上だけで行われます。［保存］では、毎回、保存する場所と名前を指定します。名前の初めの値は「元の名前_fax.pdf」なので、そのまま保存すれば元のファイルは残ります。元のファイルと同じ名前を選んだときは、置き換えてよいかの確認が出ます（3.4）。ページの材料として追加したファイルは、変えません。
- **保存の途中で失敗しても、元のファイルを壊しません**：保存は、同じフォルダに一時的な名前で書き終えてから、目的の名前に置き換えます。

## 1.4 情報はどこに置かれるか

| 情報 | 置かれる場所 |
|---|---|
| 開いた文書・ページの編集・変換の途中のデータ | メモリの中だけ（一時ファイルは作りません）。閉じると消えます |
| 保存した PDF | ［保存］で指定した場所 |
| 送付書の入力（宛先・事件・書類の一覧・通信欄など） | 送付書を入れた文書を保存したときだけ、保存した PDF と同じフォルダの「FAX送付書データ」フォルダ（3.10） |
| 設定（FAX サービスの選択・処理内容の既定値・保存の設定・送付書の送信者・最後にファイルを開いたフォルダの場所・ウィンドウの大きさと位置） | `%APPDATA%\VA_FAX\settings.json` |
| カスタムのプロファイル | `%APPDATA%\VA_FAX\profiles\` |
| ログ | `%APPDATA%\VA_FAX\logs\`（技術の情報〔ページ番号・解像度・エラーの種類など〕だけ。ファイルの名前・場所は書きません。30 日・30 ファイルまで） |
| 誤りの記録 | `%APPDATA%\VA_FAX\errors.json`（エラーの種類と、プログラムの中の場所だけ。新しいものから 30 件） |
| 外部 | 送りません |

設定ファイルには、送付書の送信者（事務所名・住所・電話・FAX・弁護士名）と、最後にファイルを開いたフォルダの場所が入ります。フォルダの名前に依頼者名が入っていることがあるので、設定ファイルを AI に渡さないでください。「FAX送付書データ」フォルダには、宛先や事件の情報が入ります。

Mac では、`%APPDATA%\VA_FAX` の代わりに、ホームの `.va_fax` フォルダを使います。

# 第2章 導入

| `マニュアル\` | この操作マニュアル（PDF） |
| `LICENSE`（インストールしたフォルダでは `LICENSE.txt`） | VA FAX のライセンス（MIT License） |
| `THIRD_PARTY_NOTICES.txt` | VA FAX が使っている部品（Python・PDF の処理の部品など）のライセンスの表示 |
| `README.md` | 配布物の説明 |
| `source\` | ソースコード一式（第9章） |

VA FAX は、「VA Documentシリーズ（統合版）」のインストーラーにも入っています（VA mints・VA Document・VA Request も入っています）。インストールの途中で、入れるツールを選べます。

## 2.2 起動のしかた

1. `VA_FAX.exe` を好きなフォルダ（デスクトップなど）に置き、ダブルクリックして起動します。インストール・Python は要りません（統合版でインストールしたときは、スタートメニューの「VA FAX」から起動します）。
2. **起動に数秒〜十数秒かかることがあります。** 必要なファイルを1つにまとめた形式（onefile）のため、起動のたびに中で展開しています。画面が出るまでお待ちください。
3. 初めて起動するときに「Windows によって PC が保護されました」と出たときは、［詳細情報］→［実行］を押します。署名のない実行ファイルに一般的に出るものです。内容に不安があるときは、`source\` のソースコードを確かめるか、ご自身の環境でビルドし直して使ってください。

ウィンドウの大きさ・位置（最大化していたかどうかを含む）は、閉じたときのものを覚えていて、次に起動したときに元に戻ります。

## 2.3 動作環境

- Windows 10・11（64bit）

Mac では、同梱のソースコード（`source\` フォルダ。GitHub の VBA-Assets/VA_FAX と同じもの）から動かせます（動作は保証しません。Mac の実機では動作を確かめていません）。Mac 用の実行ファイルは配っていません。Python 3（Tk の入ったもの。python.org の macOS 用インストーラーの Python には入っています）を入れ、ターミナルで `source` フォルダに移って、`python3 -m pip install -r requirements.txt` で必要な部品を入れてから、`python3 src/main.py` で起動します。

- **標準の MOT/FAX は Mac から使えません。** MOT/FAX の公表仕様では、利用できる機器が Windows PC・Android・iPhone で、Mac は含まれていません。Mac では、お使いのサービス（MOVFAX・メッセージプラス・秒速FAX送信など）を選んでください。そのサービスを Mac から使えるかは、各サービスの案内で確かめてください。
- Ctrl のキー（Ctrl+O・Ctrl+S・Ctrl+Z など）は、⌘ でも効きます。右クリックは、2本指のクリックか、Control キーを押しながらのクリックでも行えます。

## 2.4 アンインストール

- 配布物（zip）から使っているときは、`VA_FAX.exe` を消します。統合版でインストールしたときは、Windows の［設定］→［アプリ］→［インストールされているアプリ］で「VA Documentシリーズ（統合版）」を選び、［アンインストール］を押します。
- 設定・ログ・誤りの記録は、`%APPDATA%\VA_FAX` に残ります（エクスプローラーのアドレス欄に `%APPDATA%\VA_FAX` と入れると開きます）。要らなければ、このフォルダを消してください。統合版のアンインストールでは、このフォルダも消すかを尋ねます。
- 保存した PDF と、「FAX送付書データ」フォルダは消えません。

| ファイル・フォルダ | 内容 |
|---|---|
| `settings.json` | 設定（1.4） |
| `profiles\` | カスタムのプロファイル |
| `logs\` | ログ |
| `errors.json` | 誤りの記録（3.11） |

# 第3章 使い方

## 3.1 画面の見方

メイン画面は、上の**リボン**と、その下の左右2つの領域に分かれています（左右の境目はドラッグで動かせます）。ウィンドウの題名には、開いているファイルの名前が `送信票.pdf - VA FAX` のように出ます。まだ保存していない作業があるときは、名前の前に「＊」が付き、リボンの［保存］が青い枠で囲まれます（`＊送信票.pdf - VA FAX`）。ふつうの PDF を開いた直後も、まだ送る形（二値化など）にしていないので「＊」が付きます。保存すると消えます。「何もしない」でページ番号もオフ、ページも編集していないときは、保存しても同じものしかできないので、付きません。

**上：リボン** — Word などと同じ形のボタンの並びで、操作に使うボタンがすべてここにあります。「ファイル」「ページ」「送付書」の3つの組に分かれています。

| 組 | ボタン | 説明 |
|---|---|---|
| ファイル | 開く | PDF ファイルを開きます（3.4） |
| ファイル | 保存 | 選んだ処理内容で変換して、場所と名前を指定して保存します（3.4） |
| ファイル | 閉じる | 今の文書を閉じて、ページのない文書にします（3.4） |
| ページ | 追加 | PDF・画像のページを、選んでいるページの後ろに入れます（3.5） |
| ページ | 削除 | 選んでいるページを取り除きます |
| ページ | 回転 | 押すとメニューが開き、「左に90°回転」「右に90°回転」「180°回転」から選びます |
| ページ | 元に戻す・やり直す | ページの編集を、1つずつ戻し、また進めます |
| 送付書 | 作成（編集） | 送付書（兼受領書）を作って、文書の先頭に入れます。作成済みのときは文字が「編集」になり、送付書を直せます（3.10） |

ボタンにマウスを重ねると、少し間をおいてそのボタンの説明が出ます。押せないボタンでは、押せるようになる条件が出ます。ウィンドウの幅が狭いときは、入りきらない組が次の段に折り返されます。

画面の上のメニューバーには、［ファイル］と［ヘルプ］があります（第5章）。

**左：プレビュー欄（ページの一覧）** — ページのサムネイルの一覧と、選んでいるページの拡大表示です。サムネイルの下にはページ番号が出ます。サムネイルは、ページの選択・並べ替え・削除にも使います（3.5）。下に「変換イメージ：1 / 3 ページ目」のような表示の状態が出ます（3.7）。

**右：操作欄（上から順に）**

| 項目 | 説明 |
|---|---|
| 対象サービス | 選んでいる FAX サービスと制約値（例「MOT/FAX（上限3MB・A4）」） |
| 診断結果 | ページ数・用紙サイズ・カラーの有無・テキストの有無など。ページを編集するたびに更新されます |
| 処理内容の選択 | 圧縮方式などの変換の設定（3.6） |
| 進み具合と結果 | 保存の進み具合と、「保存しました：送信票.pdf（3ページ、120KB。上限 3MB）」のような、いちばん新しい結果 |

## 3.2 初めて起動したとき：FAX サービスを選ぶ

初めて起動したときに「お使いの FAX サービスを選んでください」という画面が出ます。契約しているサービスを選んで［決定］を押してください。ここで選んだサービスの制約（容量上限・対応用紙）に合わせて変換します。後から変えるときは、［ファイル］→［オプション…］の「FAX サービス」のタブで変えます（4.1）。

「カスタム」を選ぶと、サービス名・最大ファイルサイズ・ページ数上限・対応用紙サイズなどを自分で入力できます（一覧にないサービスを使うとき）。

## 3.3 基本の流れ

1. リボンの**［開く］**で、送りたい PDF を開きます（ウィンドウへのドラッグ＆ドロップでも開けます）。送付書を付けて複数の書面を送るときは、起動したとき（または［閉じる］の後）のページのない文書に、［追加］で書面を入れることもできます
2. 送信票などのページを足すときは**［追加］**、要らないページは**［削除］**、向きの違うページは**［回転］**で整えます（3.5）。送付書を VA FAX で作るときは、送るページをすべて入れてから、「送付書」の組の**［作成］**を押します（3.10）
3. **診断結果**と左の**プレビュー**（変換した後の見込み）を確かめます
4. 必要なら**処理内容**を変えます（ふつうは初めの設定のままで問題ありません）
5. **［保存］**を押し、保存する場所と名前を指定します（初めの値は「元の名前_fax.pdf」。開いたファイルに上書きするときは、同じ名前を選びます）

保存すると、プレビューが「保存した結果」（実際に保存した内容）に切り替わります。あとは、保存した PDF を FAX サービスの画面でアップロードするだけです。

## 3.4 ファイルを開く・保存する

**ページのない文書** — VA FAX を起動したときと、［閉じる］の後は、ページのない新しい文書になっています。［追加］でページを入れ、必要なら送付書を作って（3.10）、［保存］できます。題名は、保存するまで「新しい文書」です。保存の画面の名前と場所の初めの値は、初めに入れたファイルから決まります（例：`準備書面（1）.pdf` を初めに入れたら `準備書面（1）_fax.pdf`。送付書だけのときは `送付書_fax.pdf`）。ページを入れるまでは、［保存］は押せません。

**開く**（Ctrl+O。メニューでは［開く…］） — PDF ファイルを1つ選んで開きます。開いたファイルが、その文書の保存先になります。ファイルをウィンドウへドラッグ＆ドロップしても開けます（ページのない文書のまま何もしていないとき。複数のファイルを落とすと、1つ目を開き、残りをその後ろに追加します。それ以外のときに落としたファイルは、ページとして追加します。3.5）。

**画像を開いたとき** — JPEG・PNG の画像を［開く］で選ぶと、名前のない新しい文書として開きます（画像のファイルを PDF で書き換えないため）。題名には、保存するときの名前の初めの値（「元の名前_fax.pdf」）が出ます。

**保存**（Ctrl+S。リボンの大きいボタン。メニューでは［保存…］） — 選んだ処理内容（3.6）で変換して、保存の画面で指定した場所と名前に保存します。保存の画面には、初めに、開いたファイルの名前に「_fax」を付けた名前（例：`契約書.pdf` → `契約書_fax.pdf`）と、そのファイルのフォルダが入っています（付けるかどうかと、付ける文字は、［ファイル］→［オプション…］で選べます。4.3）。以後は、指定したファイルがその文書の保存先になります。ページの材料として追加したファイルと同じ名前では保存できません（材料のファイルは書き換えません）。

- **開いたファイルに上書きするとき**は、保存の画面で、開いたファイルと同じ名前を選びます。置き換えてよいかの確認が出ます。二値化・グレースケールのときは、画像にしたもので置き換わり、元に戻せません。
- ［上書き保存］と［名前を付けて保存］の区別はありません。どちらも［保存］で、保存の画面で名前を選びます。VA FAX は、元の PDF から FAX 用の PDF を別に作るツールなので、名前の初めの値を元のファイルと別の名前にし、元のファイルを残します。

同じ文書をもう一度保存するときは、前に保存した結果ではなく、開いたときのページから作り直します（変換を重ねて画質が落ちることはありません。処理内容を変えて保存し直すこともできます）。

**閉じる**（Ctrl+W） — 今の文書を閉じて、ページのない文書にします（VA FAX は閉じません）。1回の送信の分を保存し終えたら、［閉じる］で閉じてから、次の送信の分を始めます（前の文書を画面に残したまま、次の文書を作らないようにするためです）。ページのない文書のまま何もしていない間は、押せません。［新規作成］のボタンはありません。VA FAX を終えるときは、ウィンドウの右上の［×］を押します。

**保存していないとき**（題名に「＊」があるとき） — 文書を閉じる・別のファイルを開く・VA FAX を閉じるときに、「「（名前）」を保存していません。保存しますか？」と尋ねます（［保存する］［保存しない］［キャンセル］）。PDF を開いて中身を見ただけのときも尋ねるので、送る形のファイルを作らないときは［保存しない］を選んでください。

**VA FAX で保存したファイルを開いたとき** — VA FAX で二値化・グレースケールにして保存したファイルを開くと、圧縮方式の初めの値が「何もしない」になります（もう一度変換して画質が落ちることを防ぐため）。ページを入れ替えるだけなら、そのまま保存してください。

## 3.5 ページの編集

ページの編集は、保存するまで画面の上だけで行われ、ファイルは変わりません。

**選択** — 削除・回転などの操作は、先に対象のページをサムネイルで選んでから行います。サムネイルをクリックすると、そのページが青い枠で囲まれ、これが操作の対象です。複数のページを選ぶときは、**Shift** キーを押しながらクリック（範囲）するか、**Ctrl** キーを押しながらクリック（1ページずつ）します。すべて選ぶには **Ctrl+A** を押します。**PageUp・PageDown**、**Home・End** でも選択が移ります（**Shift** キーを押しながら **PageUp・PageDown** を押すと、範囲が広がります）。

**追加** — リボンの**［追加］**で、PDF・画像（JPEG・PNG）のファイルを選びます（複数選べます）。そのページが、選んでいるページの後ろ（何も選んでいないときは末尾）に入ります。ファイルを**サムネイルの間へドラッグ＆ドロップ**すると、落とした位置に入ります（入る位置が青い線で出ます）。追加したページは、選んだ状態になります。一度に 10 件を超えて追加しようとしたときは、確認の画面が出ます。

- 画像は、1枚につき1ページになります。画像に解像度の情報があり、その実寸が用紙（A4 など）に収まるときは実寸のページに、それ以外は用紙に収まる大きさのページになります。スマートフォンの写真の向きの情報も反映します。写真の位置情報などは、保存する PDF に入りません。

**削除** — ページを選んで、リボンの**［削除］**か、**Delete** キーを押します。サムネイルを**欄の外へドラッグして放す**方法でも削除できます（マウスのカーソルがゴミ箱の絵に変わったところで放してください）。最後の1ページは削除できません。

**並べ替え** — 動かしたいページのサムネイルをマウスでつかんで、入れたい位置まで動かして離します（つかんだ時点でそのページが選ばれるので、先にクリックしておく必要はありません）。動かしている間、入る位置が青い線で出ます。複数のページを選んでからその中をつかむと、選んだページがまとめて動きます。マウスを欄の上端・下端に近づけると、一覧が自動でスクロールします。途中でやめたいときは、マウスのボタンを離す前に **Esc** キーを押します。

**回転** — ページを選んで、リボンの**［回転］**を押し、開いたメニューから「左に90°回転」「右に90°回転」「180°回転」を選びます。横倒しのページや逆さまのページを直すときに使います。

**元に戻す・やり直す** — ページの編集（追加・削除・並べ替え・回転）は、**Ctrl+Z**（元に戻す）で1つずつ戻し、**Ctrl+Y**（やり直す）でまた進められます。保存した後も、文書を閉じるまでは戻せます。処理内容の選択（圧縮方式など）を変えたことは、元に戻すの対象になりません。

**右クリックのメニュー** — サムネイルを右クリックすると、ページの各コマンド（追加…・削除・左に90°回転・右に90°回転・180°回転・元に戻す・やり直す）のメニューが出ます。選んでいないページの上で右クリックすると、そのページだけを選んでからメニューが出ます。

## 3.6 処理内容の選択

［保存］のときに行う処理は、画面の右で、チェックボックス・ラジオボタンで確かめて選びます。選択肢の副作用（「カラー・階調情報が失われます」など）は、画面にも出ます。ファイルを開くたびに、処理内容の既定値（4.2）に戻ります。

**圧縮方式**

| 選択肢 | 説明 |
|---|---|
| **二値化（白黒・G4 圧縮）**（初めの値） | 白黒2値に変換します。カラー・階調の情報は失われますが、FAX で最も一般的な原稿の形式で、ファイルも小さくなります |
| **グレースケール（JPEG 圧縮）** | 濃淡を残します。写真・図版が中心の資料向けです。ただし、サービス側で黒つぶれ・白飛びが起こる場合があるため、実際に送信して仕上がりを確かめてください |
| **何もしない** | ページを画像にせず、そのまま保存します（文字のデータ・カラーが残ります）。すでに送信用の形式になっているファイルのページを入れ替えるだけのときなどに使います。サービスによっては送信できない場合があります |

二値化の**ディザ方式**は「自動」（初めの値）のままにしておくと、ページの内容から合う方式を1ページずつ自動で選びます（文字・線画のページには単純閾値、写真・グラデーションのページには誤差拡散）。「単純閾値」「誤差拡散」に固定することもできます。グレースケールの **JPEG 品質**は、高・中（初めの値）・低から選びます。

**容量超過時の処理方式** — 保存するファイルがサービスの容量上限を超えたときの対処の方法です。

| 選択肢 | 説明 |
|---|---|
| **解像度・品質を下げて再実行**（初めの値） | 画質を段階的に下げて1つのファイルに収めます。送信回数を増やさずに済みます |
| **分割して再実行** | 画質を下げずに、複数の PDF に分割します（3.8） |
| **何もしない** | 上限を超えていても、そのまま保存します。保存の後に、大きさと上限を知らせます |

「解像度・品質を下げて再実行」の**削減方式**は、「原因ページのみ」（初めの値。容量の大きい写真のページなどだけ画質を下げ、ほかのページの画質は保つ）と「全体を均等に」（全ページを少しずつ下げる）から選べます。

**用紙正規化**（初めの値：オン） — 対応外の用紙サイズ・向きのページを自動で直します。B4・A3 などの大きいページは A4 に縮小して収め（縮小率は診断結果に出ます）、A4 より小さいページは拡大せずに A4 の中央に原寸のまま置きます。横向きのページは、サービスが横向きに対応していないときに回転して縦向きに収めます。オフにすると、対応外サイズのページを含む文書は保存できません（エラーになります）。［ファイル］→［オプション…］の「処理内容の既定値」でオフにすると、この項目は画面に出なくなり、用紙正規化を行いません（4.2）。

**ページ番号を入れる**（初めの値：オン） — 保存する各ページの上端の中央（用紙の端から 5mm）に、「1/12」の形で通し番号を入れます。受け手は、送付書の「本書を含め12枚」と照らして、全ページが届いたか、抜けや順番違いがないかを確かめられます。送付書（3.10）も1ページ目として数えます。容量を超えて分割したときも、ファイルをまたいだ通し番号になります。番号の下地は白く塗るので、ページの上端に文字があっても読めます（VA FAX で番号を入れて保存したファイルに入れ直したときは、前の番号が隠れます）。番号はプレビューでも確かめられます。圧縮方式が「何もしない」のときも入れられます（ページの中身はそのままで、番号だけを重ねます。VA FAX で保存したファイルのページを入れ替えたときに、画質を落とさずに番号を付け直せます）。［ファイル］→［オプション…］の「処理内容の既定値」でオフにすると、この項目は画面に出なくなり、番号を入れません（4.2）。

**圧縮方式が「何もしない」のとき** — ページを画像にしないので、「解像度・品質を下げて再実行」と用紙正規化は効きません。この2つは選べない状態になり、その理由が画面に出ます（容量超過時の処理方式が「解像度・品質を下げて再実行」だったときは「何もしない」に切り替わり、圧縮方式を戻すと元に戻ります）。また、ページ数の上限や対応外の用紙サイズがあっても保存は止めず、保存の後に、送信の制約に合っていない点を知らせます。

## 3.7 プレビューの見方

プレビュー欄の下の表示で、いま見ているものが分かります。

| 表示 | 意味 |
|---|---|
| **変換イメージ：1 / 3 ページ目** | 保存の前。いまの処理内容で変換したときの**見込み**を出しています |
| **そのままの表示（画像にしません）：1 / 3 ページ目** | 圧縮方式が「何もしない」のとき。ページをそのまま出しています |
| **保存した結果：1 / 3 ページ目** | 保存の後。実際に保存した PDF **そのもの**を出しています |

処理内容（圧縮方式・ディザ方式など）を変えると、変換イメージが自動で更新されます。保存の後は保存した結果の表示に切り替わり、自動の調整（画質を下げたことなど）があったときも、その結果を確かめられます。処理内容を変えるかページを編集すると、変換イメージの表示に戻ります。

拡大表示するページの切り替えは、サムネイルのクリックのほか、PageUp・PageDown キー（前後のページ）、Home・End キー（先頭・末尾）、拡大表示の上でのマウスホイールでも行えます。

## 3.8 容量を超えて分割されたとき

容量超過時の処理方式が「分割して再実行」で、実際に分割が起きたときは、保存先と同じフォルダに `文書名_1of3.pdf` `文書名_2of3.pdf` `文書名_3of3.pdf` のような連番のファイルを作ります。

- **保存先のファイル（開いたファイル）そのものは書き換えません。** そのため、文書は未保存のままになります（題名の「＊」は消えません）。
- 終わったときのお知らせに、作ったファイルの名前が出ます。［フォルダを開く］で、その場所を開けます。プレビューには、最初のファイルが出ます。
- 同じ名前の分割のファイルがすでにあるときは、保存せずにエラーになります。前のファイルを移動・削除するか、［保存］で別の名前を指定してください。

| Ctrl+S | 保存（Ctrl+Shift+S でも同じ） |
| Ctrl+W | 閉じる |
| Ctrl+Z ・ Ctrl+Y | 元に戻す ・ やり直す |
| Delete | 選んでいるページを削除（サムネイルの欄を操作した後） |

## 3.10 送付書（兼受領書）を作る

訴訟で相手方に書面を FAX で直送するとき（民事訴訟規則 47 条）の送付書を、VA FAX の中で作れます。作った送付書は、文書の先頭のページになり、ほかのページと同じく、処理内容（二値化など）に従って保存されます。法令や裁判所が定めた様式はないため、実務でよく使われる項目で作ります。

**初めに一度だけ：送信者の入力** — ［ファイル］→［オプション…］の「送付書」のタブで、事務所名・住所・電話番号・FAX 番号・弁護士名を入力して［保存］を押します（4.4）。空の項目は、送付書に書きません。

**作り方**

1. 送る書面（準備書面・証拠説明書・書証など）を、送る順に入れます。ページのない文書（起動したとき・［閉じる］の後）に［追加］で入れるか、1つ目を［開く］で開いて、残りを［追加］で入れます
2. リボンの「送付書」の組の**［作成］**を押すと、入力の画面（題名「送付書」）が開きます
3. 宛先（裁判所の係と、相手方の代理人）、送信者の肩書（例：原告訴訟代理人弁護士）、事件番号などを確かめて、**［OK］**を押します

送付書が文書の先頭に入ります（プレビューで確かめてください）。送付書を入れると、ボタンの文字が**［編集］**に変わります。直すときは、［編集］を押すか、**送付書のページ（サムネイルまたは拡大表示）をダブルクリック**して入力の画面を開き、［OK］を押すと、直した送付書に差し替わります。送付書を入れる・差し替えるのも、ページの編集の1つとして、元に戻せます（Ctrl+Z）。

**入力の画面の項目**

| 項目 | 説明 |
|---|---|
| 送信日 | 初めは今日の日付（和暦） |
| 宛先 | 裁判所（「御中」を付けます）と、相手方（敬称は「殿」「先生」「様」から選びます）。それぞれ FAX 番号を書けます。裁判所の欄が空なら、裁判所の宛先は書きません |
| 送信者 | 肩書を入力します。事務所名などは、オプションで入力したものを使います |
| 事件 | 事件番号・事件名・当事者。空の項目は書きません |
| 送付する書類 | 書類の名前と枚数。**初めは、文書に入れたファイルの名前から作ります**（下の説明）。行を直す・足すことができます。空の行は書きません。［ファイルから作り直す］で、いまの文書から作り直します |
| 通信欄 | 次回期日の連絡など、自由に書けます。何も書かないときは、送付書に通信欄の枠を書きません |
| 受領書の欄を付ける | 初めはオン。オンのときは、表題が「送付書（兼受領書）」になり、下半分に、相手方が記名押印して返送する受領書の欄が付きます（受領書は、相手方が送信者と裁判所に FAX で返します。民事訴訟規則 47 条の2第3項）。訴訟以外の送付では、オフにします |

**書類の一覧の作り方** — 文書に入れたファイルごとに1行を作り、枚数は、いまの文書に残っているそのファイルのページ数にします（送付書自身は数えません）。VA mints の命名による証拠のファイル（`甲001 売買契約書.pdf`、枝番の `甲005-2 写真.pdf` など）は「甲第1号証」「甲第5号証の2」と書き、番号が続くものは「甲第1号証〜第3号証」「甲第5号証の1〜3」のように1行にまとめます。それ以外のファイルは、ファイルの名前（拡張子を除く）をそのまま書きます。

**送信枚数** — 送付書には「送信枚数 本書を含め N 枚」と書きます。N は、送付書を含めた文書のページ数です。送付書を作った後にページを追加・削除して、送信枚数とページ数が合わなくなったときは、保存するときに知らせます（［送付書を直す］［このまま保存］［キャンセル］）。

**入力の初めの値と保存** — 送付書を入れた文書を保存すると、その入力（宛先・事件・書類の一覧・通信欄など。事務所名などの送信者は除く）を、保存した PDF と同じフォルダの**「FAX送付書データ」フォルダ**に、`（保存したPDFの名前）.json` として保存します。次のときに、入力の画面の初めの値として使います。

- その PDF を VA FAX で開いて［編集］を押したとき：保存したときの入力（1ページ目を送付書とみなし、差し替えます）
- 同じフォルダで、別の文書の送付書を作るとき：そのフォルダでいちばん新しい入力の、宛先・事件・肩書（同じ事件の書面を続けて送るときに、入力の手間が減ります）
- どちらもなく、VA mints で証拠説明書を作ったフォルダのファイルを入れたとき：VA mints の証拠説明書の入力（`証拠説明書データ\証拠説明書.json`）の、裁判所・事件番号・提出者（肩書）

「FAX送付書データ」フォルダには、宛先や事件の情報が入ります。FAX サービスにアップロードするのは、保存した PDF だけです。フォルダごと人に渡すときは、このフォルダを含めてよいかを確かめてください。

# 第4章 オプション

［ファイル］→［オプション…］で開く画面で、設定をまとめて変えられます。画面は「保存」「処理内容の既定値」「FAX サービス」「送付書」の4つのタブに分かれています。［保存］を押すと、すべてのタブの内容が保存されます（［キャンセル］では何も変わりません）。保存の処理の途中は開けません。

## 4.1 FAX サービス

初めて起動したときと同じ並びで、お使いのサービスを選びます。サービスを切り替えると、制約値（容量上限・対応用紙）と診断結果が、新しいサービスに合わせて更新されます。

ほかのサービスから「カスタム」に替えるときは、［保存］を押したときに、カスタムの内容（サービス名・最大ファイルサイズ・ページ数上限・対応用紙サイズなど）を入力する画面が開きます。カスタムを選んでいる間は、［カスタムの内容を入力…］で内容を変えられます。

## 4.2 処理内容の既定値

ファイルを開いたときの処理内容の初めの値を、まとめて決められます。項目は、圧縮方式（二値化・グレースケール・何もしない）・ディザ方式・JPEG 品質・容量超過時の処理方式（解像度・品質を下げて再実行・分割して再実行・何もしない）・削減方式・用紙正規化・ページ番号の各初めの値です。用紙正規化・ページ番号をオフにすると、メイン画面の処理内容の選択にその項目が出なくなり、その処理を行いません（使わない事務所向け）。値を変えて保存すると、開いている文書の処理内容も、新しい既定値に戻ります。

メイン画面で変えた処理内容は**その文書限り**で、次にファイルを開くと、ここで決めた既定値に戻ります（共有の PC でも、誰が使っても同じ初めの状態から始まるためです）。

## 4.3 保存

| 項目 | 説明 |
|---|---|
| ［保存］の画面に初めに入るファイル名に、次の文字を付ける（初めの値：オン、付ける文字は「_fax」） | ［保存］の画面に初めに入る名前と、画像を開いた文書の名前に、この文字を付けます（`契約書.pdf` → `契約書_fax.pdf`）。付ける文字は「-fax」「_送信用」などに変えられます（20 文字まで。`\ / : * ? " < > \|` は使えません）。オフにすると、開いたファイルと同じ名前（拡張子は .pdf）になります。どちらのときも、保存の画面で名前を変えられます |
| 保存の後に、保存したフォルダを開く（初めの値：オフ） | 保存の後に、保存したフォルダをエクスプローラーで開きます。FAX サービスの画面へアップロードするときに、ファイルを探す手間が減ります |

## 4.4 送付書

送付書（3.10）の送信者の欄に書く、事務所名・住所（2行まで）・電話番号・FAX 番号・弁護士名を入力します。空の項目は、送付書に書きません。肩書（例：原告訴訟代理人弁護士）は、事件ごとに違うので、送付書を作るときに入力します。

## 4.5 複数の PC で設定をそろえる

設定ファイル `%APPDATA%\VA_FAX\settings.json` をほかの PC の同じ場所へ写すと、オプションの内容（FAX サービスの選択・処理内容の既定値・保存の設定・送付書の送信者）をまとめてそろえられます（Mac では、ホームの `.va_fax` フォルダにあります）。

# 第8章 AI を使ってツールを改造するとき

VA FAX はソースコードを公開しており（第9章）、事務所独自の機能を、AI（プログラムを書くのを手伝う AI）を使って足すこともできます。その場合は、次の手順で、**AI が実データ（依頼者・事件の情報）に届かない場所で作業させてください。**

## 8.1 なぜ注意が必要か

AI が読んだファイルや画面は、AI の会社のサーバーに送られます。依頼者の情報を AI に読ませると、守秘義務の点で問題になり得ます。AI は作業の途中で、思わぬファイルを開くことがあります。そのため、「気をつけて使う」だけでは防げません。AI が実データに届かない場所で作業させてください。

## 8.2 手順1　AI 専用の Windows ユーザーを作る

- ［設定］→［アカウント］→［他のユーザー］で、AI の作業に使うユーザーを作ります。管理者にはせず、標準ユーザーにします。
- このユーザーでは、事務所の OneDrive・SharePoint にサインインしません。共有フォルダ・ネットワークドライブ・暗号化した仮想ドライブにもつなぎません。
- 作ったら、このユーザーでエクスプローラーを開き、事務所の共有データの場所が見えないこと、開けないことを確かめます。見える場合は、そのフォルダのアクセス許可からこのユーザーを外してください。
- 別の PC を AI の作業に使えるなら、さらに確実です。

## 8.3 手順2　このユーザーで、ソースと試用データだけを使って作業する

- ソースは、このユーザーで新しく手に入れます。サイトから配布物（zip）をダウンロードし直し、`source` フォルダのソースコードを使います（GitHub から取ってもかまいません）。ふだんのユーザーのフォルダから写さないでください。
- 試すときは、架空の文書か、付属のスクリプト（`source\samples\make_samples.py`）で作る架空のサンプルの PDF を使います。実際の事件の書類は使いません。
- 設定ファイル（`%APPDATA%\VA_FAX`）は、このユーザーで VA FAX を起動して新しく作られたものを使います。ふだんの設定ファイルを写さないでください（最後に開いたフォルダの場所など、フォルダの名前に依頼者名が入ることがあります）。「FAX送付書データ」フォルダも写さないでください。
- 実データの中身を、AI に貼り付けたり、画面の写しで見せたりしないでください。
- 不具合を AI に相談するときの渡し方は、第7章「不具合のご連絡」のとおりです（［ヘルプ］→［診断情報をコピー］）。

## 8.4 手順3　実データでの確認と入れ替えは、ふだんのユーザーで人が行う

- 改造してできた VA FAX（ソースから動かすもの、または作り直した実行ファイル）を、ふだんのユーザーに移します。
- データのバックアップを取ってから、まず実データの写しで試し、問題がなければ使い始めます（VA FAX の［保存］は、開いたファイルと同じ名前を選ぶと、そのファイルを書き換えるので、必ず写しで試してください）。
